# Edge Spine 위젯 구현 계획

**목표:** 선택된 1번 목업을 Mac 가장자리의 더블클릭 할 일·메모 위젯으로 구현한다.

**구조:** 56px 펫은 대기 진입점으로 유지한다. 한 번 클릭은 기존 빠른 기능 바를 즉시 열고, 두 번째 클릭은 그 바를 닫고 가장자리에 붙은 전용 세로 패널을 연다. 위젯은 기존 `AppModel`의 로컬 할 일·메모와 초안을 공유하며 집중 상태에서는 열리지 않는다.

**기술:** SwiftPM macOS 14+, AppKit `NSPanel`·`NSEvent`, SwiftUI, macOS 26 Liquid Glass/구버전 재질.

## 작업 1 — 이벤트와 창

- [x] 기존 앱에서 펫 더블클릭으로 위젯이 열리지 않는 상태를 확인한다.
- [x] `WindowCoordinator.swift`의 `PetClickView`에 더블클릭 콜백을 추가한다. `mouseUp`에서 드래그하지 않았고 펫 안에서 끝난 클릭만 처리하며, 클릭 수 1은 빠른 바, 2는 전용 위젯으로 보낸다.
- [x] 같은 파일에 전용 `KeyPanel`을 추가한다. 할 일 크기 288×420, 메모 크기 288×304를 기준으로 펫의 오른쪽 가장자리에 맞추고 `visibleFrame` 안으로 y를 제한한다.
- [x] 위젯을 열면 빠른 바·메시지를 닫고 펫을 숨긴다. 위젯을 접으면 펫을 같은 가장자리 위치에 복구한다. Esc, 집중 시작, 화면 변화, 드래그 때도 창 상태가 어긋나지 않게 한다.

## 작업 2 — 전용 내용

- [x] `CompactWidgetView.swift`에 펫 얼굴을 포함한 헤더, 할 일 입력·목록·완료/삭제, 메모 입력·저장, 할 일/메모 전환, 접기 동작을 만든다. 여섯 기능 레일과 Hub 버튼은 넣지 않는다.
- [x] `AppModel.swift`에 위젯 전용 선택 상태를 둔다. 위젯을 새로 열 때 할 일을 기본으로 하고, 현재 초안과 저장 데이터는 기존 빠른 바와 동일하게 유지한다.
- [x] 패널은 공통 `moonlightGlassPanel`을 써 macOS 26의 시스템 글래스와 이전 버전의 흐림 재질을 이어받는다. 펫 얼굴은 56px 이내로 유지하고 원형 테두리를 만들지 않는다.

## 작업 3 — 확인과 기록

- [x] `swift run MoonlightPetPreview --self-check`와 `./script/build_and_run.sh --verify`를 통과시킨다.
- [x] 실제 앱에서 한 번 클릭 빠른 바, 더블클릭 위젯, 초안 유지, 메모 입력 초점, 위젯 접기·재열기, Esc를 확인한다. 저장 데이터의 추가·제거·복원은 격리 저장소를 쓰는 자체 점검으로 확인한다.
- [x] 선택된 1번 시안과 구현 결과·남은 장비 확인 범위를 `2026-09-24-macos-edge-pet-mockup-design.md`에 기록한다.
