# 데스크톱 펫 마이크로 편의성

사용자 요청: 완료 체크 몇 초 뒤 목록에서 숨김, 리마인드·도착 표시, 쾌적도 개선.

## 이번 범위

- 저장 성공한 완료 항목을 원래 위치에 3초간 유지한다. 재클릭으로 취소 가능하며 이후 기본 목록에서 숨긴다. 기록은 삭제하지 않고 목록 보기 메뉴에서 완료 포함을 선택할 수 있다.
- 기존 일정 10분 전 리마인드와 펫 빨간 숫자 배지를 유지한다. 말풍선 닫기와 읽음 처리를 분리한다. 문의·일정 확인 시 해당 로컬 배지만 감소하고 Hub 미확인 문의 수는 변경하지 않는다.
- 목록 메뉴에서 개별/전체 로컬 확인 가능. 읽음 기록은 Hub origin별로 보존하고 신규 문의 revision은 다시 미확인이다. 기존 Council 대화 확인은 해당 담당자·범위의 알림을 제거하는 계약 유지.
- 말풍선 종료 후 1초 간격으로 다음 알림을 시도한다. 기존 창 조정자가 입력·집중 상태에서 표시를 거절하면 소비하지 않고 나중에 표시한다.
- 기존 유리 재질 수치·캐릭터 색상·창 구조 유지. OS 시스템 알림은 이번 범위에 포함하지 않는다.

## 구현 / 검증 순서

1. 완료 항목의 표시 지연을 저장과 분리하고 Hub 완료 응답을 확인한다.
2. 알림의 origin별 읽음 상태·이전 저장 형식 호환·대기열 처리를 추가한다.
3. 기존 목록과 메뉴에 연결하고 모션 감소 설정을 존중한다.
4. 격리된 데이터로 지연·취소·재완료·읽음 복구·알림 순서를 검증한다. Hub 쓰기 실패/재연결 회귀 검사와 네이티브 빌드·self-check를 실행한다.
5. 이 변경만 커밋하고 주 작업 브랜치에 통합한 뒤 앱을 재실행한다.
