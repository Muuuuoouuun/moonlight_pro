# 사이드바 아이콘 레일 개선

목표: 운영자 요청에 따라 사이드바를 56px 아이콘 레일로 최소화하고 허브와 어울리는 SVG 아이콘을 제공한다.

설계: 기존 232px/56px 두 상태를 유지한다. 하나의 DOM으로 접기 버튼의 키보드 포커스를 보존한다. 모바일에서는 기존 전체 드로어를 사용한다. localStorage 접근은 hydration 이후에 수행하고 실패하면 세션 상태로 작동한다. 작업 범위 아이콘은 현재 범위를 알리고 클릭하면 전체 사이드바를 펼쳐 선택된 범위로 포커스를 이동한다. 메뉴 구조·라우팅은 그대로 유지한다.

- [x] 현재 내비게이션·디자인 계약과 저장 설정을 확인하고 전용 워크트리 생성.
- [x] hub-preferences.test.mjs에 접기 상태 저장·복구·차단된 저장소 테스트 추가, 구현 전 실패 확인.
- [x] hub-preferences.js와 hub-app.jsx에 sidebarCollapsed 저장 및 hydration 이후 복구 연결.
- [x] hub-sidebar.jsx와 hub-tokens.css에서 안정된 DOM·아이콘 레일·검색·범위·알림 구현.
- [x] hub-icons.jsx에 패널·체크리스트·고객 연락·나침반 SVG 추가하고 hub-nav.js에서 의미에 맞게 연결.
- [x] 내비게이션·환경설정·디자인 계약 테스트와 브라우저에서 최소화→탐색→새로고침→펼침, 모바일 메뉴 검증.

검증 결과: 관련 node 테스트 56개 통과. 브라우저 1280×720 및 390×844에서 레일 56px·가로 넘침 없음·메뉴 이동·새로고침 복원·검색·범위 포커스·모바일 전체 드로어 및 ESC 포커스 복원 확인. 콘솔 error/warn 0건. 데이터 연결이 없는 preview 환경이며 라이브 업무 데이터 쓰기는 수행하지 않았다. 독립 코드 검토에서 차단 이슈 없음.
