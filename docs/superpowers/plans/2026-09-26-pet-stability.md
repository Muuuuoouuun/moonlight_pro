# 데스크톱 펫 전반 점검·안정화

사용자 요청: 위젯·앱의 버그·연결 누락·최적화를 점검하고 수정·커밋.
기존 승인된 유리 질감·캐릭터와 Hub 쓰기/읽기 계약을 유지한다.

## 확인한 문제와 수정

1. 같은 origin 연결 확인이 인증 세션과 대화를 초기화함 → 정규화된 같은 주소는 API 재사용. 승인한 origin을 반환해 거절된 입력이 브라우저 목적지를 바꾸지 못하게 함.
2. 확인된 메모 충돌이 pending에 갇힘 → transport/data conflict 처리. 재시작에도 충돌 보호를 유지하고 명시적 새 항목 저장으로 복구. 잘못된 ID/누락 영수증은 미확인 상태 보존.
3. 새 메모 길이 검증 실패가 원격 메모 연결을 지움 → 입력 검증 후 연결 변경.
4. 숨겨진 Council 뷰가 읽음을 소비하고 재개방은 놓침 → 활성 화면 기준 읽음 처리. 연결 설정은 읽음 대상에서 제외하고 뒤의 ⌘Return/⌘S 실행도 차단.
5. 고정 위젯에 할 일 열기를 요청해도 기존 화면 유지 → 모드·크기·포커스 갱신.
6. 일정 선택일과 주간 스트립의 주가 다름 → 선택 주 표시, 기존 더보기에 오늘/이전 주/다음 주 제공.
7. polling Task가 self를 sleep 동안 계속 보유 → 작업 중에만 소유하고 모델 해제 시 취소. 같은 활성 화면 재할당·중복 시작 방지. 집중 타이머의 같은 초 중복 publication 제거.

## 검증

- 수정 전 재현 실패: 같은 origin 세션 보존, polling 모델 해제, 숨겨진 Council 읽음 소비.
- Hub 모델/API 계약: 인증 재사용, 거절된 주소, 메모 충돌·재시작·명시적 복구, 검증 실패 후 동일 메모 ID 유지.
- 전체 native script/test_*.sh 및 swift self-check. GPU·글리프 렌더링·완료/알림·Office 대화 계약 포함.
- localhost 실제 Hub 읽기: 할 일 39개·주간 일정 6개, partial=false. 운영 기록 수정이나 실제 AI 생성은 실행하지 않음.
- 실행 중인 Council 대화·입력을 보존하기 위해 현재 프로세스를 종료하지 않음. 통합 뒤 메인 체크아웃에서 빌드 검증. 새 UI의 실제 창 조작은 진행 중 대화 때문에 검증하지 않음.

## 현재 제품 범위

집중 모드는 화면 차단 프로토타입이며 네트워크 웹사이트 차단기가 아니다. 담당자 대화·초안은 앱 실행 중 메모리에 유지된다. OS 알림·종료 중 리마인드·AI 실데이터 자동 탐색은 이번 안정화에서 추가하지 않았다.
