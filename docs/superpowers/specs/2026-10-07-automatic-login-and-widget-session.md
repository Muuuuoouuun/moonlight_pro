# 자동 로그인과 위젯 세션 연결

> 상태: 운영자 요청에 따라 구현·로컬 검증 완료 / 운영 배포 전.
> 관계: `2026-09-23-operator-password-login-design.md`의 12시간 고정 만료와 `2026-10-05-pet-auto-login-design.md`의 Mac 전용 자동 로그인에 Electron 셸·위젯 세션 공유를 추가한다. 10-05에 승인된 아이디·비밀번호 키체인 보관과 인증 거절 이후의 제한된 재시도는 유지한다.

운영자 요청은 자동 로그인과 로그인된 앱에 위젯이 함께 연결되는 것이다.

- 웹·Electron 로그인 화면의 `자동 로그인 · 30일 유지`는 기본 선택이다. 선택 해제하면 기존 12시간이다. API는 `rememberMe: true`일 때만 30일을 발급하고 서명된 토큰과 쿠키의 만료를 일치시킨다. 사용 중 만료를 연장하지 않는다.
- 유효한 세션으로 로그인 화면을 열면 원래 목적지로 계속 이동한다. Council 안건의 전달·충돌 검토를 보존한다.
- Electron 메인 창과 Windows 위젯은 같은 영속 세션을 사용한다. 위젯에서 로그인으로 넘어갔다면 메인 창 로그인 후 위젯을 다시 연다. 쿠키 변경 후에는 이전 위젯 페이지를 재조회한다.
- Mac 네이티브 펫·위젯은 기존 10-05 계약대로 서버가 수락한 아이디·비밀번호를 origin별 키체인에 보관한다. 자체 로그인은 30일 세션을 요청하며, 쿠키는 전용 메모리에만 둔다. 재시작·자연 만료 후에는 기존 키체인 자동 로그인 경로로 인증한다.
- Mac Electron 셸이 실행 중이면 같은 사용자의 Unix 소켓으로 현재 Hub의 운영자 세션만 공유한다. 부모 디렉터리 권한은 0700, 소켓은 0600이고 네이티브 클라이언트는 소켓 서버의 UID도 확인한다. 다른 origin·만료된 세션은 받지 않는다. 세션은 URL·명령행 인자·일반 설정 파일·로그에 넣지 않는다.
- 네이티브 로그인 결과는 셸 쿠키에도 반영한다. 셸의 쿠키 변경은 비밀값 없는 `session-changed` 알림으로 펫 조회를 갱신한다. 명시적 로그아웃은 쿠키와 키체인을 비운다. 셸이 없을 때는 기존 네이티브 자동 로그인 경로를 사용한다. 명시적 로그아웃과 자연 만료를 구별해 자연 만료는 기존 자동 인증을 막지 않는다.
- 외부 브라우저의 쿠키 저장소까지 공유하지 않는다. 서버의 인증·same-origin 쓰기 경계와 미설정 시 차단은 유지하며 공개 API나 DB 변경은 없다.

검증은 루트 회귀, 데스크톱 회귀, Swift transport/domain, 실제 Node↔Swift 소켓 통신, 독립 프로세스의 키체인 복원·삭제, Mac 앱 빌드·서명 확인을 포함한다. Windows 실기 검증과 운영 배포는 별도다.

Swift transport 26개와 domain·실제 키체인·소켓 검사, 네이티브 self-check, Hub 프로덕션 빌드, Mac 번들 빌드·서명 검증을 통과했다. 격리한 Electron 스모크에서 메인/위젯 세션 일치와 로그인 후 자동 재연결을 확인했다. 브라우저에서는 로그인 성공 및 유효한 세션으로 `/login?next=%2Fwidget`을 열 때 재로그인 없이 위젯으로 이동함을 확인했다.
