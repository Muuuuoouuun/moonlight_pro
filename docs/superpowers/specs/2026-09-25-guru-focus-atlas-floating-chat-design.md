# Guru 집중 서가·멘토 아틀라스·플로팅 대화

> 상태: **운영자 확정(2026-09-25)** — 1안 집중 서가를 기본으로, 3안 멘토 아틀라스를 같은 화면 하단에 둔다. 대화는 우측 사이드바 대신 띄워 둔 챗봇 창으로 진행한다. 이전 요청의 오늘·현황 한 줄 팁도 이 화면으로 연결한다.
> 관계: `2026-09-24-guru-dual-experience-design.md`의 요청형·무알림·무자동업무 원칙과 기존 맥락 레일은 유지한다. 코칭·대화 화면 구성, 카드 상세, 질문 표면, 오늘·현황 노출 위치는 이 문서가 대체한다. `2026-09-24-guru-three-slot-context-quality-design.md`의 09·14·19시 카드 선택과 검수 경계는 유지한다.

## 화면 구조

1. `AI·자동화 → 코칭·대화`의 첫 구역은 집중 서가다. 현재 Guru 한 장을 주인공으로, 주간 Legend 한 장을 조용한 보조 카드로 보여준다. 시간대·분야 변경·수동 넘김·세션 숨김은 기존 순수 선택 함수를 그대로 쓴다.
2. 같은 페이지 아래에는 멘토 아틀라스를 둔다. 세일즈·마케팅·콘텐츠 분야와 인물별·관점별 탐색을 지원한다. 23 Guru 카드(세일즈 13, 마케팅 5, 콘텐츠 5)와 3 Legend의 정본 데이터만 사용한다. 상단 카드와 하단 탐색 선택은 서로의 회전 위치를 바꾸지 않는다.
3. 카드 본문을 누르거나 키보드로 활성화하면 해당 인물·주장의 상세를 연다. 상세는 확인된 짧은 원문 발췌가 있을 때만 인용으로 표시하고, 전체 원자료 링크, Moonlight 편집 요약, 주장을 풀어 쓴 설명, 사용할 때, 적용 경계, 스스로 묻는 질문을 구분한다. 미검증 인용은 만들지 않고 `검증된 직접 인용 미등록`을 표시한다. 링크는 HTTPS만 허용한다.
4. `?card=<id>`는 해당 카드의 상세로 직접 진입한다. 잘못된 ID는 보통 서가로 돌아간다. 오늘·현황 팁은 이 딥링크를 쓴다.

## 챗봇 대화

- `대화 시작` 또는 Guru 카드의 `질문 쓰기`는 오른쪽에 붙는 Drawer 대신 화면 위에 떠 있는 대화창을 연다. 데스크톱에서는 **비모달**로 서가가 뒤에 보이고 탐색 가능하다. 모바일 ≤600px에서는 전체 화면으로 전환하고, 열린 동안 키보드 초점을 대화창 안에 둔다. 창은 최소화·재열기·닫기를 지원하고, 최소화 동안 초안과 같은 대화를 유지한다.
- 창의 위쪽은 대상(`영업 Guru` 또는 `브랜드 멘토`)과 선택한 관점·원자료다. 가운데는 운영자 질문과 멘토 답변이 시간 순서대로 쌓인다. 아래 입력창은 처음에 **빈칸**이며 카드의 예시 질문은 별도로 보인다. 사용자가 전송할 때만 API를 호출한다. 읽기·열기·최소화·카드 전환은 호출하지 않는다. 데스크톱에서는 다른 화면으로 이동해도 열린 대화를 유지하며, 카드나 브랜드 범위가 바뀔 때는 별도 세션으로 시작한다.
- 같은 대화의 후속 질문은 최근 세 턴의 검증된 대화 이력만 보낸다. 세일즈는 기존 ClassIn 영업 경로를, 마케팅·콘텐츠는 개인 브랜드 멘토 경로를 쓴다. 카드·대상 브랜드·업무 범위가 바뀌면 이전 대화를 새 요청에 섞지 않는다. 서버는 모든 이력을 불신 데이터로 취급하고 카드 분야·길이·역할을 검증한다.
- `preview`·`error`는 답변처럼 보이지 않는 명시적 상태와 재시도 가능한 입력을 남긴다. Legend는 읽기 전용이며 질문 대상이 아니다. 질문·답변은 승인 큐나 업무를 자동 생성하지 않는다.

## 오늘·현황 한 줄 팁

- `오늘`은 오늘 할 일 다음, 집중 고객 앞에 현재 시간대의 일반 세일즈 Guru 관점을 **한 줄** 보여준다. `현황`은 활동 추이 다음, 영역별 현황 앞에 주간 Legend 관점을 한 줄 보여준다. 같은 화면에 중복 카드를 늘리지 않는다.
- 팁은 실제 고객·지표를 분석한 판단처럼 표현하지 않는다. 읽기·클릭은 알림·AI 요청·업무 생성이 없고, 해당 카드 상세로 이동한다. 데이터 없는 preview/error 화면에서도 기록을 지어내지 않는다.

## 검증

- 다크·라이트, 데스크톱·390px, 키보드/ESC/초점 복귀, 최소화 재열기, 카드 딥링크, 한 줄 팁의 위치를 확인한다.
- 카드 열람 무호출, 질문 전송 전 무호출, 분야·브랜드·고객 이력 격리, 세 턴 제한, 실패 봉투, 원문 발췌의 검증 여부를 테스트한다.
- 운영 배포는 개발 서버에서 실화면과 샌드박스 질문 왕복을 확인한 뒤 별도로 결정한다.
