# 데스크톱 펫 — 실제 Hub 연결

상태: 사용자 요청 승인(2026-09-25). 기존 펫의 유리 질감·레이아웃 계약을 유지한다.
관계: 2026-09-24 macOS edge pet 목업의 로컬 전용 데이터 경계를 이 문서가 확장한다.

## 범위

- 할 일: Hub 목록 조회, 빠른 생성, 완료/완료 취소. 자세한 편집·삭제는 Hub에서 한다.
- 메모: Mac 자동 저장을 유지하고 명시적 `Hub에 저장`으로 현재 메모함에 저장한다. 같은 메모의 후속 저장은 revision을 확인한다.
- 일정: 선택한 주/날짜의 실제 Hub 캘린더를 조회한다. 편집은 브라우저에서 한다.
- Office/Council과 상세 화면은 기존처럼 브라우저로 연다.

## 연결

기존 Hub API와 운영자 세션을 재사용한다. 새로운 공개 엔드포인트나 데이터베이스 변경은 없다.
HTTPS와 정확한 로컬 HTTP 주소만 허용하고, API 리다이렉트는 거부한다. 운영자 비밀번호를 저장하지 않는다.
세션은 앱 전용 메모리 쿠키 저장소에 둔다. 앱 재시작 후 인증이 필요하면 연결 화면에서 로그인한다.
현재 개발 서버의 loopback 동작은 서버가 판정한다. 클라이언트가 인증 우회를 추가하지 않는다.

## 데이터와 실패

- Hub 목록과 기존 Mac 기록을 혼합하지 않는다. 연결 설정에서 Mac 기록으로 돌아갈 수 있다.
- 연결 성공 전/오류/partial/preview를 빈 목록이나 저장 완료로 표시하지 않는다.
- 추가/완료는 서버의 저장 확인 뒤 반영한다. 실패한 입력을 지우지 않는다.
- 새 할 일은 안정적인 UUID로 재시도한다. 완료 변경은 원래 updatedAt 문자열을 보존해 충돌을 감지한다.
- 메모는 journal API에 안정적인 requestId·entryId·occurredAt·expectedRevision으로 저장하고 동일 ID의 본문을 다시 읽어 검증한다.
- 주소 변경·연결 해제 후 늦게 도착한 응답은 현재 화면에 반영하지 않는다.
- 이전 로컬 할 일을 자동 업로드하지 않는다. 사용자 기존 기록은 UserDefaults에 그대로 남긴다.
- 화면을 열 때 새로고침하고 열린 동안만 주기적으로 조회한다. 수동 새로고침도 제공한다.

## 검증

격리한 SwiftPM 테스트로 API 응답·오류·중복·충돌·지연 응답·초안 보존·일정 날짜를 확인한다.
실제 Hub에는 조회만 수행해 연결 상태를 확인한다. 검증용 업무 기록을 운영 DB에 생성하지 않는다.
기존 self-check, 앱 번들 빌드, 실제 창 확인을 통과한 뒤 통합하고 재실행한다.
