# 자동화·Guru 역할 재정렬

> 상태: 운영자 승인(2026-09-26, 대화의 방향 전체 승인 및 구현 지시).
> 관계: 09-24 에이전트 계층 방향과 09-25 Guru 서가·요청형 대화를 유지한다. 09-24 Guru 도움 카드 및 계층 방향 §6.6의 구형 일괄 생성 엔드포인트 수동 유지 결정을 대체한다.

## 승인한 경계

- 정기 운영은 승인된 수집·동기화·계산이다. AI 초안·요약·검토는 기존 업무 화면에서 운영자가 요청한다.
- followup-autopilot·content-flywheel·chief-of-staff의 구형 일괄 GET 실행은 중단한다. 인증 후 410 disabled를 반환하고 모델·업무·실행 기록을 생성하지 않는다. 기존 고객 답장·Office·Studio·멘토 API는 유지한다.
- 자동화 목록에는 중단 상태를 명시하고 기존 실행 기록은 보존한다. DB의 active를 실행 예약의 증거로 해석하지 않는다.
- 홈은 현재 활성 정기 운영의 최근 미회복 실패만 보여 준다. 동일 자동화의 반복 실패는 한 건으로 묶고 이후 성공한 실패는 제외한다. 요청형 AI·의도적 중단은 홈 경고에서 제외한다.
- 실행 기록의 자동화 ID가 빠져도 output_payload.key로 식별한다. 날짜를 포함해 과거 기록을 오늘처럼 보이지 않게 한다.

## 구현 판단

홈의 최근 범위는 기존 운영 지표와 같은 24시간으로 시작한다. 결과가 확정된 success/failure 중 최신 결과를 기준으로 회복을 판정하며 queued/running/ignored는 회복으로 보지 않는다. 원인을 알 수 없는 실행은 로그에 보존한다. 중단된 엔드포인트의 실제 예약은 발견된 호출원에서 해제하고, 조사 범위와 미확인 경로를 기록한다.
