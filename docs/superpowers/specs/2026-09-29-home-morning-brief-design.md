# 홈 하단 아침 브리핑

> 상태: **운영자 시안 승인·구현 지시(2026-09-29)**. 기존 Home의 Futura 시각 언어와 하단 배치를 유지한다. 화면 속 예시 수치·일정은 실제 데이터로 쓰지 않는다.
> 관계: `2026-09-21-home-today-overview-role-design.md`의 홈을 짧은 시작 화면으로 보려는 권장안과 `2026-09-25-guru-focus-atlas-floating-chat-design.md`의 오늘·현황 한 줄 팁 위치 규칙을 이번 홈 한 구역에 한해 보완한다. 오늘·현황의 기존 팁은 유지한다.

## 목적과 위치

`dashboard/home`의 기존 신호 처리와 `오늘의 시간표`를 유지한다. 시간표 다음, 키보드 단축키 안내 앞에 `아침 브리핑` 한 구역을 둔다. 데스크톱과 390px 모바일에서 같은 순서다. 한 번에 읽는 사실 3줄과 기존 Guru 관점 팁 1줄을 한 카드 안에서 보여준다. 별도 팁 카드·새 탭·알림은 만들지 않는다.

## 내용

1. **먼저 확인:** `/api/hub/daily-brief`의 확인된 긴급 KA 1건, danger 신호, 기한을 넘긴 집중 고객, 기한을 넘긴 할 일 순으로 확인 가능한 첫 항목 하나만 쓴다. 어떤 원장이든 실패/미연결이면 0건처럼 말하지 않는다. 모두 확인됐고 후보가 없을 때만 `지금 먼저 확인할 긴급 항목이 없습니다`를 쓴다.
2. **다음 일정:** Home 시간표와 같은 `/api/calendar/google/event` 응답에서 끝나지 않은 시각 일정 한 건을 쓴다. 일정 없음·일부 캘린더 미확인·연결 필요·읽기 실패는 각각 다른 문구다. 종일 일정은 시각 일정에 섞지 않는다.
3. **오늘의 진척:** `taskToday.focus`의 실제 `picked/done`만 쓴다. 0개를 고른 날은 선택 전임을 말하고, 읽기 실패는 `진척 확인 불가`로 둔다. AI 추천을 사용자가 고른 항목으로 표현하지 않는다.
4. **한 줄 팁:** 기존 `<GuidanceInlineTip variant="today">`가 고르는 현재 시간대 세일즈 Guru 자료 요약을 위 사실 세 줄 아래, 행동 버튼 위에 둔다. 문구를 재작성하거나 고객·일정 분석 결과처럼 표현하지 않는다. 클릭은 기존 `?card=<id>` 글로 이동하고 AI 호출·업무 생성은 없다.

## 행동과 상태

- `오늘 열기`는 기존 `dashboard/daily-brief`로 이동한다. `30초 AI 브리핑 열기`도 같은 화면의 기존 요청형 AI 구역으로 안내한다. 홈 진입·팁 읽기만으로 AI를 실행하지 않는다.
- 홈의 기존 두 GET 응답을 재사용한다. 새로운 API·DB·예약 실행은 없다. 읽기 실패는 HTTP 200 `status:error` 봉투까지 확인한다.
- 로딩에는 카드 자리의 `Skeleton`을, 오류·미연결에는 `TruthBadge`와 확인 가능한 줄만 보여준다. 마지막 조회 시각을 오늘 최신 사실로 오인하게 하는 고정 문자열은 쓰지 않는다.
- Futura 토큰·프리미티브·1px 선·모바일 터치 44px을 지킨다. 기존 트리아지·시간표를 고치거나 페이지 히어로를 하나 더 만들지 않는다.

## 완료 기준

- 사실 3줄과 팁이 시간표와 단축키 사이에 보인다. 팁은 중복된 새 콘텐츠가 아니라 기존 시간대 선택 결과와 같은 딥링크다.
- 정상·부분·미연결·오류 응답에서 `없음`과 `확인 못함`이 섞이지 않는다.
- 390px에서 가로 넘침과 44px 미만 행동 버튼이 없다. 다크·라이트에서 기존 Home 위계가 유지된다.
