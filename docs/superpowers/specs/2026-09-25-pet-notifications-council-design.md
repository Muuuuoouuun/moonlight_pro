# 펫 알림 · Council 안건 준비

## 관계와 범위

2026-09-25 Hub 연결을 이어 사용자 요청한 알림·Council 개발을 진행한다. 브라우저 우선, 기본 투명 유리, 원본 메모 보존 결정을 유지한다. 브랜드 Council과 Office 9인 회의는 별개다.

## 이번 구현

- 실제 Hub 미확인 문의와 앞으로 10분 안에 시작하는 시간 지정 일정을 펫 알림함에 표시한다. 문의 상세는 브라우저, 일정은 펫 일정으로 연다.
- 앱 실행 중 60초 간격으로 조회한다. 일정 조회 기간은 지금부터 24시간이며 화면에서 선택한 주와 독립적이다. 종일 일정은 시간 알림 대상에서 제외한다.
- 기존 미확인 문의는 첫 연결에서 목록만 채운다. 새 문의/새 수신 메시지는 한 번 말풍선으로 알린다. 일정은 시작 시간별 한 번. 동일 Hub origin의 전달·숨김 상태는 Mac에 보존한다.
- 말풍선은 입력 포커스를 가져오지 않는다. 집중 중·패널 사용 중에는 보류하고, 지난 일정은 뒤늦게 알리지 않는다. 말풍선 끄기와 Mac에서 숨기기를 제공한다. 서버 읽음 처리는 상세 화면에서 한다.
- 연결 실패는 빈 알림함과 구별한다. 이전 조회는 남겨두되 실패 출처를 표시한다. Hub 변경/로컬 전환 때 이전 Hub 알림을 지운다.
- Council은 직접 입력·현재 메모·할 일을 편집 가능한 안건으로 준비한다. 원본 입력을 변경하지 않고 안건 초안은 Mac에 보존한다.
- 명시적인 ‘Council에서 검토’는 `/dashboard/agents/council#moonlight-council=...`로 초안을 전달한다. version 1 JSON + base64url, draft 최대 4000 UTF-16, 전체 fragment 최대 24000자. source.kind는 text/memo/task만 허용한다.
- Hub는 fragment를 메모리로 옮기고 주소에서 제거한다. 기존 입력을 덮어쓰지 않는다. 로그인 경유 때에도 정확한 Council 대상과 유효한 payload만 이어준다. AI 호출은 사용자가 Hub의 실행 버튼을 누를 때만 한다.

## 한계

앱 종료 중 시스템 푸시·백그라운드 데몬, AI 실행 완료 알림, 자동 메시지 발송은 이번 범위에 포함되지 않는다. 일정·문의 API의 부분 조회/페이지 한도는 UI에 드러낸다.
