# 펫 데스크톱 — 승인된 글래스 활용 시안 적용

상태: 2026-09-24 운영자 확정. 세 이미지 목업의 질감·구성·사용감을 실제 네이티브 앱에 적용한다.

관계: `2026-09-24-macos-edge-pet-mockup-design.md`의 Edge Spine 크기·할 일/메모 전용 탭과 빠른 바의 6개 상시 기능 레일을 이 문서가 대체한다. 한 번 클릭 빠른 기능, 두 번 클릭 지속 위젯, 브라우저 상세 연결, 로컬 저장 및 집중 차단의 경계는 유지한다.

## 화면

- 오늘: 좁고 긴 패널, 날짜, 할 일/일정 2개 세그먼트, 빠른 입력과 평평한 목록. 데이터는 사용자가 저장한 로컬 할 일만 쓴다. 일정은 실제 날짜와 Hub 연결 상태를 표시하며 이미지의 예시 회의는 넣지 않는다.
- 빠른 메모: 가로로 넓어지는 입력면, 로컬 자동 저장 상태, 메모를 복사하고 Council을 브라우저에서 여는 명시적 동작. AI 메시지를 자동 제출하지 않는다.
- 집중: 불투명 전체 화면 위에 작은 펫, 스모크 글래스 타이머, 진행선, 중지와 Esc 길게 안내. 중지 확인과 원래 macOS 상태 복귀를 유지한다.
- Office·Council·집중 시작·Hub 주소 설정은 공통 더보기로 접근한다. 기존 ⌘1~6은 유지한다. 탭을 바꿔도 초안은 유지하고 창의 위쪽/오른쪽 기준점을 지킨다.

## 재질과 펫

떠 있는 패널은 승인 시안의 밝은 실버 외관, 집중 화면은 흑연 외관을 사용한다. AppKit 네이티브 regular 글래스 한 층이 배경을 샘플링한다. Clear 재질은 밝은 배경에서 글자 대비가 부족해 채택하지 않았다. 내용은 별도 불투명 회색 배경으로 가리지 않는다. 여백, 한 픽셀 곡선 윤곽, 가까운 그림자, 얇은 컨트롤로 승인 이미지의 깊이를 구현한다. 글래스의 배경 의존성은 그대로이며 생성 이미지의 광학 효과와 일치한다고 단정하지 않는다. 동작·투명도 줄이기와 대비 증가에 대응한다.

2026-09-24 추가 확정: 기본 대기 아이콘과 짧은 메시지에는 원본 얼굴 이미지를 쓴다. 펼친 지속 위젯과 집중 모드에서만 팔을 걸친 투명 배경 포즈를 유리 상단에 얹는다. 위젯에는 상단 투명 여백 54pt와 72pt 캐릭터를 두고 유리와 18pt 겹친다. 아홉 원본은 보존한다. 블래키는 추가 제공된 일자 앞머리 원본으로 교체한 별도 자산을 쓰며, 에브이는 뒤 묶음 머리가 작은 실루엣에서도 드러나게 유지한다. 이미지 생성으로 별도 투명 배경 펫 자산을 만들고 작은 크기에서 검토한다. 펼친 포즈에 사각 타일이나 원 테두리를 두지 않는다. 대기 얼굴은 원본 배경을 유지한다. 호버·누름·해제와 전환만 짧게 반응하며 무한 장식 모션은 없다.

## 검증

격리 UserDefaults로 기존 저장과 새 초안 복원을 확인한다. 세로↔가로 전환의 화면 경계와 앵커, 실제 클릭·키보드·메모 저장, 집중 중지/복귀를 확인한다. 실행 앱은 빌드 경로까지 검증한다. 운영 Hub 데이터와 인증은 수정하지 않는다.
