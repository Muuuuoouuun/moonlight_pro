# 펫 숫자 알림 · 담당 에이전트 즉시 대화

## 관계

운영자의 후속 요청으로 2026-09-25 알림·Council 설계를 확장한다. 펫 Council의 기본 행동은 현재 캐릭터 담당 Office 에이전트에게 질문하고 같은 창에서 답변받기다. 브랜드 Council 브라우저 검토는 더보기에 보존한다.

## 결정

- 펫과 짧은 말풍선의 캐릭터 위에 빨간색 숫자 배지를 표시한다. 알림 0개는 숨기고 100개 이상은 99+로 표시한다.
- 기본 담당자는 현재 펫 캐릭터와 동일하다. Office 9인 담당 및 전체/회사/개인 범위를 사용자가 선택할 수 있다.
- 원문 메모·할 일을 질문 초안으로 가져오거나 직접 입력한다. 보내기를 누를 때만 기존 인증된 Office chat API를 호출한다.
- 답변과 다음 행동을 같은 창에서 읽고 이어서 질문한다. 원격 업무 변경·발송을 하는 기능은 추가하지 않는다.
- 대화 이력과 미전송 초안·출처는 앱 실행 중 메모리에만 유지하고 Hub origin·담당·범위를 분리한다. 최근 4왕복만 각 2,000 UTF16자로 제한해 문맥으로 보낸다. 입력은 최대 6,000 UTF16자다. 브랜드 Council 브라우저 전달은 별도 명시 행동이며 기존 전달 초안 저장을 유지한다.
- 한 번에 요청 하나. 자동 재전송은 하지 않는다. 기다림 중단·실패·시간 초과 때 입력은 보존한다. 서버에는 요청 영수증 조회나 멱등 키가 없어 다시 보내기는 새 요청이다.
- 전송 중에는 담당/범위 메뉴를 잠그고, 펫 외형을 바꿔도 전송 대상은 유지한다. 연결을 바꾸거나 기다림을 중단한 뒤 늦게 도착한 응답은 현재 대화에 섞지 않는다. 답변이 와도 사용자가 새로 쓴 입력과 공백·줄바꿈 편집을 지우지 않는다.
- 창을 닫아도 기다림은 계속되고 답변 도착을 펫 알림으로 남긴다. 집중 중엔 말풍선을 보류하며 알림에서 해당 담당/범위 대화로 돌아온다.
- Office chat POST 경로만 기존 웹과 맞는 긴 시간 제한을 적용한다. 기존 CRUD 인증·시간 제한은 유지한다.

## 검증

격리된 API 응답으로 request/response 계약, 중복 전송, 늦은 응답, 취소와 새 입력 보존, 범위 분리를 검증한다. 실제 운영 AI 호출은 시험하지 않는다. Swift 빌드·기존 자체 검사 및 앱에서 배치·동작을 확인한다.
