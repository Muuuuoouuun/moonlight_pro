# Moonlight macOS 가장자리 펫 목업

상태: 운영자 승인 흐름의 시연용 목업. 제품 구현·운영 배포 결정은 별도다.

## 목표와 범위

기존 Hub를 유지하면서 Mac 가장자리의 작은 펫에서 빠른 입력과 집중 모드로 이어지는 사용감을 검증한다. 목업은 별도 SwiftPM GUI 앱으로 만들며 Hub의 데이터·인증·서버 코드는 수정하지 않는다. 할 일과 메모는 사용자 입력만 이 Mac의 로컬 저장소에 기록한다. 일정·Office·Council은 기능 바에서 브라우저 Hub의 해당 경로로 이동한다.

## 네 상태

1. **대기:** 주 화면 오른쪽 가장자리 아래쪽 ⅓에 56px 펫 하나를 둔다. 원형 테두리와 창 그림자는 쓰지 않는다. 전체 화면 앱 위에는 나타나지 않는다.
2. **메시지:** 메뉴 막대의 `짧은 메시지 보기`에서 선택한 캐릭터와 함께 최대 두 줄로 로컬 할 일/메모 상태를 보여준다. 실제 Hub·AI 알림 연결은 이 목업에 없다.
3. **빠른 기능 바:** 펫 한 번 클릭 또는 단축키로 연다. 할 일·일정은 좁고 긴 창의 세로 기능 레일과 목록·브라우저 연결 영역을 쓴다. 메모·Office·Council·집중은 가로 기능 바로 돌아간다. 창의 크기·위치가 짧게 전환되고 할 일/메모 초안은 기능 이동 중에도 유지한다. 자세한 화면은 브라우저 Hub로 연다.
4. **집중:** 시작 전 시간을 고른다. 시작하면 각 화면을 덮는 클릭 차단 창과 주 화면의 타이머가 나타난다. 타이머와 중지 외의 앱 조작은 받지 않는다. 중지는 확인을 거치며 Esc를 길게 눌러도 같은 확인 화면을 열 수 있다. 시간이 끝나면 창을 닫고 기존 Mac 상태를 돌린다.

## 기술 경계

- SwiftUI는 표시와 입력을 맡고, AppKit은 펫 패널·화면별 차단 창·창 위치를 맡는다.
- 제공받은 아홉 캐릭터 이미지를 원본 그대로 앱 리소스로 사용한다. 이름은 이브이와 여덟 진화체의 한국어 이름이며 기본 캐릭터는 글레이시아다. 우클릭 메뉴에서 바꾸고 선택을 로컬에 저장한다. 가장자리 아이콘과 메시지에는 같은 캐릭터를 표시한다.
- Hub 주소는 사용자가 설정할 수 있고, 목업 기본값은 로컬 개발 서버 `http://127.0.0.1:3000`이다. 서버 자격 증명이나 비밀번호를 앱에 넣지 않는다.
- macOS 프레젠테이션 옵션으로 Dock/메뉴 및 앱 전환을 집중 중 숨긴다. 강제 종료를 막지 않는다. OS 보안 화면과 시스템 단축키까지 완전 차단한다고 약속하지 않으며 실제 Mac에서 검증한다.
- 빠른 기능 바와 짧은 메시지 창은 macOS의 흐림·반투명 재질을 공유한다. macOS 26에서는 화면 뒤를 흐리는 `NSVisualEffectView` 위에 틴트 없는 시스템 `glassEffect`를 두고, 이전 버전은 기존 HUD 재질을 쓴다. 글래스의 색은 배경이 비쳐 보이는 정도와 텍스트 대비를 실제 밝고 어두운 화면에서 확인해 조정한다. 패널 창의 직각 그림자는 끄고 둥근 표면에만 1px 선을 그린다. 가장자리 펫은 테두리 없이 두고 집중 차단 창은 불투명하게 유지한다.
- 펫은 유휴 상태에서 움직이지 않는다. 포인터 진입에는 아주 작은 확대·기울기·들림을, 누름에는 짧은 스프링 압축을, 놓을 때에는 감쇠된 복귀를 준다. 드래그 중에는 누름과 다른 축소 상태를 유지하고, 캐릭터 변경은 짧게 교차 전환한다. 바·메시지는 열릴 때 160ms 동안 4px 이동과 페이드를, 닫힐 때는 120ms 페이드를 쓴다. 기능 내용과 창 크기는 180ms 이내에 전환한다. 집중 타이머는 매초 숫자만 갱신하고 중지 확인에만 160ms 전환을 준다. macOS의 동작 줄이기가 켜지면 모든 장식적 움직임을 건너뛴다.
- Hub `DESIGN.md`의 무채색 Moonstone 팔레트, 1px 선, 짧은 패널 전환, 움직임 줄이기를 적용한다. 펫은 계속 움직이지 않는다.

## 목업의 통과 기준

- 한 번 클릭과 단축키가 빠른 바를 안정적으로 열고, 메시지는 메뉴 막대에서 연다.
- 할 일·일정의 세로형과 나머지 기능의 가로형 전환 중 입력·기능 선택이 유지된다.
- 할 일과 메모가 사용자 입력으로 생성·수정되고 재실행 후 남는다.
- 기능을 바꾸어도 편집 중인 초안이 지워지지 않는다.
- 일정·Office·Council이 올바른 Hub 브라우저 경로를 연다.
- 집중 중 여러 화면의 배경 클릭이 앱에 전달되지 않으며 중지 확인과 Esc 길게 누르기로 빠져나온다.
- 집중 종료 후 Dock/메뉴와 펫 상태가 복구된다.

## 검증 범위

SwiftPM 빌드, 로컬 저장·집중 상태의 소규모 테스트, 앱 실행, 네 상태 시각 확인을 수행한다. 전체 화면 앱·여러 모니터·Spaces 경계는 실제 장비에서 별도로 확인하고 관찰 결과를 기록한다.

2026-09-24 초기 목업 확인: SwiftPM 빌드와 자체 상태 점검 통과. 실제 앱 창에서 이전 더블 클릭 동작, 할 일/메모 전환, 메시지 미리보기, 집중 타이머, 짧은 Esc가 종료하지 않는 동작, 중지 확인과 펫 복귀를 확인했다. 한 번 클릭 기능 바·세로형 전환은 후속 변경으로 별도 확인한다. 다른 앱 클릭·전체 화면 앱·여러 모니터·Spaces·물리 키보드의 전역 단축키와 Esc 길게 누르기는 아직 통과로 표시하지 않는다.

2026-09-24 후속 확인: 9개 캐릭터 리소스·이름을 확인했다. 56px 테두리 없는 펫을 한 번 눌러 할 일 세로형 바가 열렸고, 일정도 세로형으로 표시됐다. 메모로 바꾸면 가로형으로, 다시 할 일로 바꾸면 세로형으로 돌아오는 동작을 실제 창에서 확인했다.

2026-09-24 글래스 확인: 빠른 기능 바와 짧은 메시지 창에 공통 macOS 반투명 재질을 적용했다. 실제 앱에서 할 일 세로형과 메모 가로형을 확인했으며, 집중 차단 창과 가장자리 펫의 배경 처리는 바꾸지 않았다.

2026-09-24 모션 확인: 펫 클릭으로 바 열기·Esc 닫기, 할 일 추가·완료·삭제, 연속 기능 전환, 집중 중지 확인과 펫 복귀를 실제 앱에서 확인했다. 포인터 hover의 체감과 여러 모니터 환경은 별도 장비 확인이 남아 있다.

2026-09-24 글래스·세로형 품질 후속: macOS 26에서는 시스템 `glassEffect`에 Moonstone 틴트를 적용하고, macOS 14~25에서는 기존 `NSVisualEffectView` 처리를 유지한다. 새 시스템 글래스는 기존의 별도 불투명 덮개 없이 쓰고 패널 테두리는 1px로 유지한다. 할 일·일정은 같은 368×416 세로 패널을 써 왕복할 때 창 크기가 튀지 않는다. 일정에는 실제 날짜·이번 주 표지만 표시하고, 일정 항목은 지어내지 않는다. 일정 상세는 기존 결정대로 브라우저 Hub에서 열며 주소 편집은 접어 둔다. 실제 앱에서 두 패널 전환, 할 일 추가·삭제, 일정 주소 펼침, 메모 가로형 전환과 초안 유지를 확인했다.

## 2026-09-24 시각·반응 품질 보정

확정된 한 번 클릭 빠른 바와 할 일·일정 세로형 전환은 유지한다. 창 자체의 직각 그림자를 끄고, macOS 26의 짙은 글래스 틴트를 걷어 화면 뒤를 흐리는 재질을 받친다. 반투명도가 높아져도 조작 글자와 목록 값의 대비가 낮아지지 않는지 밝고 어두운 배경에서 확인한다. 펫은 포인터·누름·드래그·해제에만 작게 반응하며 유휴 애니메이션은 넣지 않는다. 이는 이번 목업에 구현하는 범위다.

## 권장 기획 — 더블클릭 전용 위젯

상태: **권장·미구현**. 현행 한 번 클릭 빠른 바를 대체하지 않는다. 펫을 두 번 클릭하면 56px 펫 자리에서 단일 목적의 세로 카드로 펼친다. 첫 카드는 할 일로 권장하며, 상단의 작은 전환 버튼으로 메모 카드에 바꾼다. 할 일 카드는 새 할 일 입력과 미완료 목록·완료 토글만, 메모 카드는 바로 쓰는 입력면과 저장 상태만 본문에 둔다. 여섯 기능 레일과 브라우저 연결은 기존 빠른 바에 남긴다. 위젯은 기존 로컬 할 일·메모 저장소와 초안을 공유한다.

- **한 번 클릭:** 현재처럼 빠른 바를 즉시 연다. 첫 클릭을 더블클릭 판별 때문에 지연하지 않는다. 연달아 두 번째 클릭하면 빠른 바를 닫으면서 전용 카드로 이어서 펼쳐 중간 창이 깜박이지 않게 한다. 더블클릭 판정은 macOS의 시스템 간격을 따른다.
- **크기·배치:** 할 일은 폭 약 272px의 좁고 긴 카드, 메모는 같은 폭에 내용에 맞춘 더 짧은 카드로 제안한다. 펫의 화면 가장자리 기준점에 붙이고 화면 밖으로 나가는 방향은 안쪽으로 뒤집는다. 정확한 높이와 입력 밀도는 실제 콘텐츠로 목업에서 확정한다.
- **접기·이동:** 카드의 펫 얼굴 또는 Esc로 원래 56px 펫에 접는다. 카드 헤더에서 세로로 끌어 위치를 옮기되 입력 영역의 드래그와 충돌시키지 않는다. 단축키나 메뉴에서도 같은 카드에 접근할 수 있게 한다.
- **전환 모션:** 펫과 카드의 모서리·크기·내용을 한 흐름으로 약 180~240ms 사이에 잇고, 중간에 텍스트를 늘리거나 찌그러뜨리지 않는다. 입력과 목록은 뒤따라 짧게 나타난다. 동작 줄이기에서는 크기 탄성 없이 바로 교체한다.
- **열린 결정:** 첫 카드가 항상 할 일인지, 마지막으로 쓴 할 일·메모를 기억할지는 운영자 선호를 확인한다. 카드의 정확한 크기와 더블클릭 중 빠른 바가 잠깐 보이는 처리도 실제 프로토타입에서 조정한다.

## 2026-09-24 글래스 질감 2차 보정

구현: macOS 26의 시스템 `regular` 글래스와 화면 뒤를 흐리는 AppKit popover 재질을 유지하고, 패널 가장자리의 1px 선에만 방향에 따른 미세한 밝기 차이를 준다. 표면 전체에는 색 그라데이션이나 추가 불투명 덮개를 얹지 않는다. `NSGlassEffectView` 단독과 `clear` 글래스는 실제 앱에서 밝은 회색 면으로 평평하게 보여 채택하지 않았다. 균일한 흰 바탕에서는 주변 색과 무늬가 적어 굴절이 약하게 보일 수 있으므로, 밝고 어두운 앱 창을 뒤에 둔 상태에서 최종 투과감과 텍스트 대비를 확인한다. 더블클릭 전용 위젯의 구조는 위 권장 기획을 바탕으로 세 시각 목업을 비교한 뒤 선택한다.
