# Moonlight macOS 가장자리 펫 목업

상태: 운영자 승인 흐름의 시연용 목업. 제품 구현·운영 배포 결정은 별도다.

## 목표와 범위

기존 Hub를 유지하면서 Mac 가장자리의 작은 펫에서 빠른 입력과 집중 모드로 이어지는 사용감을 검증한다. 목업은 별도 SwiftPM GUI 앱으로 만들며 Hub의 데이터·인증·서버 코드는 수정하지 않는다. 할 일과 메모는 사용자 입력만 이 Mac의 로컬 저장소에 기록한다. 일정·Office·Council은 기능 바에서 브라우저 Hub의 해당 경로로 이동한다.

## 네 상태

1. **대기:** 주 화면 오른쪽 가장자리 아래쪽 ⅓에 56px 펫 하나를 둔다. 원형 테두리와 창 그림자는 쓰지 않는다. 전체 화면 앱 위에는 나타나지 않는다.
2. **메시지:** 메뉴 막대의 `짧은 메시지 보기`에서 선택한 캐릭터와 함께 최대 두 줄로 로컬 할 일/메모 상태를 보여준다. 실제 Hub·AI 알림 연결은 이 목업에 없다.
3. **빠른 기능 바:** 펫 한 번 클릭 또는 단축키로 연다. 할 일·일정은 좁고 긴 창의 세로 기능 레일과 목록·브라우저 연결 영역을 쓴다. 메모·Office·Council·집중은 가로 기능 바로 돌아간다. 창의 크기·위치가 짧게 전환되고 할 일/메모 초안은 기능 이동 중에도 유지한다. 자세한 화면은 브라우저 Hub로 연다.
4. **집중:** 시작 전 시간을 고른다. 시작하면 각 화면을 덮는 클릭 차단 창과 주 화면의 타이머가 나타난다. 타이머와 중지 외의 앱 조작은 받지 않는다. 중지는 확인을 거치며 Esc를 길게 눌러도 같은 확인 화면을 열 수 있다. 시간이 끝나면 창을 닫고 기존 Mac 상태를 돌린다.

## 기술 경계

- SwiftUI는 표시와 입력을 맡고, AppKit은 펫 패널·화면별 차단 창·창 위치를 맡는다.
- 제공받은 아홉 캐릭터 이미지를 원본 그대로 앱 리소스로 사용한다. 이름은 이브이와 여덟 진화체의 한국어 이름이며 기본 캐릭터는 글레이시아다. 우클릭 메뉴에서 바꾸고 선택을 로컬에 저장한다. 가장자리 아이콘과 메시지에는 같은 캐릭터를 표시한다.
- Hub 주소는 사용자가 설정할 수 있고, 목업 기본값은 로컬 개발 서버 `http://127.0.0.1:3000`이다. 서버 자격 증명이나 비밀번호를 앱에 넣지 않는다.
- macOS 프레젠테이션 옵션으로 Dock/메뉴 및 앱 전환을 집중 중 숨긴다. 강제 종료를 막지 않는다. OS 보안 화면과 시스템 단축키까지 완전 차단한다고 약속하지 않으며 실제 Mac에서 검증한다.
- 빠른 기능 바와 짧은 메시지 창은 macOS의 흐림·반투명 재질을 공유한다. 어두운 Moonstone 틴트와 얇은 테두리로 글자 대비를 유지한다. 가장자리 펫은 테두리 없이 두고 집중 차단 창은 불투명하게 유지한다.
- Hub `DESIGN.md`의 무채색 Moonstone 팔레트, 1px 선, 짧은 패널 전환, 움직임 줄이기를 적용한다. 펫은 계속 움직이지 않는다.

## 목업의 통과 기준

- 한 번 클릭과 단축키가 빠른 바를 안정적으로 열고, 메시지는 메뉴 막대에서 연다.
- 할 일·일정의 세로형과 나머지 기능의 가로형 전환 중 입력·기능 선택이 유지된다.
- 할 일과 메모가 사용자 입력으로 생성·수정되고 재실행 후 남는다.
- 기능을 바꾸어도 편집 중인 초안이 지워지지 않는다.
- 일정·Office·Council이 올바른 Hub 브라우저 경로를 연다.
- 집중 중 여러 화면의 배경 클릭이 앱에 전달되지 않으며 중지 확인과 Esc 길게 누르기로 빠져나온다.
- 집중 종료 후 Dock/메뉴와 펫 상태가 복구된다.

## 검증 범위

SwiftPM 빌드, 로컬 저장·집중 상태의 소규모 테스트, 앱 실행, 네 상태 시각 확인을 수행한다. 전체 화면 앱·여러 모니터·Spaces 경계는 실제 장비에서 별도로 확인하고 관찰 결과를 기록한다.

2026-09-24 초기 목업 확인: SwiftPM 빌드와 자체 상태 점검 통과. 실제 앱 창에서 이전 더블 클릭 동작, 할 일/메모 전환, 메시지 미리보기, 집중 타이머, 짧은 Esc가 종료하지 않는 동작, 중지 확인과 펫 복귀를 확인했다. 한 번 클릭 기능 바·세로형 전환은 후속 변경으로 별도 확인한다. 다른 앱 클릭·전체 화면 앱·여러 모니터·Spaces·물리 키보드의 전역 단축키와 Esc 길게 누르기는 아직 통과로 표시하지 않는다.

2026-09-24 후속 확인: 9개 캐릭터 리소스·이름을 확인했다. 56px 테두리 없는 펫을 한 번 눌러 할 일 세로형 바가 열렸고, 일정도 세로형으로 표시됐다. 메모로 바꾸면 가로형으로, 다시 할 일로 바꾸면 세로형으로 돌아오는 동작을 실제 창에서 확인했다.

2026-09-24 글래스 확인: 빠른 기능 바와 짧은 메시지 창에 공통 macOS 반투명 재질을 적용했다. 실제 앱에서 할 일 세로형과 메모 가로형을 확인했으며, 집중 차단 창과 가장자리 펫의 배경 처리는 바꾸지 않았다.
