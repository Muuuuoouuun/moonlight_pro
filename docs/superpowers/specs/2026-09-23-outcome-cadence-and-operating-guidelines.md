## 1. '결과 월시동(月·時·動)'의 정의와 관점

Moonlight는 다기능 SaaS가 아니라 1인 운영자의 **개인 업무 집행 정본(Personal OS)**이다. 기능의 나열이 아니라, 운영자의 하루와 한 달이 실제로 굴러가는 **결과 중심 3대 척추**로 정렬되어야 한다.

```text
[ 月 : 월간 결과·목표 ]
   │  - 이 달의 지향점 및 집중 목표 (딜 클로징, 프로젝트 마일스톤, 콘텐츠 큐)
   │  - 통제 가능한 선행 지표 (Action KPI: 접촉 수, 완료율, 회고율)
   ▼
[ 時 : 시점 리듬·케이던스 ]
   │  - 09:00 아침 브리프 : 오늘의 Top 3, 긴급 KA 1건, 일정 확인
   │  - 주간 이원화 : 목요일 아침(회사/ClassIn 리포트), 월요일 아침(개인 리포트)
   │  - 17:00 저녁 회고 : 완료 체크, 에너지/진척 점검, 내일 이월
   ▼
[ 動 : 즉시 실행·원장 완결 ]
      - 생각/메모 캡처 즉시 저장 (마찰 0)
      - AI 멀티모달 구조화 (결정사항 / 미결안건 / 할 일)
      - 고객 접촉 결과 4대 필드 (요약 / 반응 / 다음행동 / 다음일정) 원자 기록
      - 결과 영수증(Receipt)으로 루프 닫힘
```

## 2. 핵심 운영 지침 (Operating Directives)

### 지침 1: 기록 마찰 제로, 확정 전 사람 승인 (Zero-Friction, Human in the Loop)
- **캡처**: 머릿속 생각, 단체 카톡, 회의 녹음, 화이트보드 사진은 5초 안에 던져 넣을 수 있어야 한다.
- **AI의 역할**: AI는 '판단자'가 아니라 **'구조화 비서'**다. 요약, 미결 안건, 후속 할 일 후보를 정리하되, 최종 등록과 외부 전송은 반드시 운영자의 1클릭 승인을 거친다. (자율 발송/임의 등록 금지)
- **정직한 상태(Honest State)**: DB나 AI가 모르는 정보는 지어내지 않고 빈 상태로 두며, 실패는 투명하게 보고한다.

### 지침 2: 열린 루프 없는 원장 완결 (No Open Loops)
- 고객과 연락했으면 반드시 다음 4가지가 원장에 남아야 한다:
  1. `1줄 요약`: 무슨 대화를 나누었는가?
  2. `고객 반응`: 긍정 / 우려 / 거절 / 무응답 / 중립
  3. `다음 행동`: 구체적으로 내가 다음에 해야 할 일
  4. `다음 날짜`: 언제 다시 연락/행동할 것인가? (날짜가 없으면 명시적 `기약 없음` 선택)
- 회의를 했으면 반드시 다음 3가지로 닫힌다:
  1. `결정사항`: 무엇이 합의되었는가?
  2. `미결안건`: 무엇이 보류되었는가?
  3. `할 일(R&R)`: 누가 언제까지 무엇을 하는가? (프로젝트 연결)

### 지침 3: 시점(時)에 맞는 정보만 노출 (Cognitive Relief)
- 아침 첫 화면에 20개의 할 일을 쏟아내지 않는다.
  - **긴급 KA 미팅 1건** + **집중 고객 3~5명** + **오늘 반드시 끝낼 Top 3**로 한정.
- 무기한 할 일이나 기약 없는 딜은 오늘 화면에서 숨기고, 전용 렌즈(무기한 탭)에서 별도로 관리한다.

## 3. 결과 월시동 디벨롭 계획 (3단계 로드맵)

### [1단계] 즉시 시동: 하루 루틴과 주간 리포트 닫기 (Short-term / ~1주)
*코드 복잡도 없이 기존 원장과 화면의 고리를 닫아 즉시 결과 측정 시작*

1. **오늘의 Top 3 지정 및 저녁 회고 루프 (時-動)**
   - 아침 브리프에서 오늘 해야 할 일 중 핵심 3개를 선택(`focus_dates`)할 수 있는 UI 제공.
   - 저녁 17:00 하루 리뷰 시 Top 3의 완료 여부를 체크하여 **"오늘의 실행 완수율"** 기록.
2. **주간 리포트 원천 오류 교정 (月-時)**
   - `getWeeklyReport`의 완료 태스크 집계를 `updated_at`에서 **실제 `completed_at` 기준**으로 교정.
   - 연락 건수 집계를 빈 테이블(`outreach_outcomes`) 대신 **실제 `crm_activities` 기준**으로 교정하여 주간 실적이 0으로 뜨는 현상 해소.
3. **회의록·메모 즉석 카톡 공유 및 실무 라우팅 실사용 안착 (動)**
   - 이번에 구현된 `[📋 공유 요약 복사]`를 활용해 회의 직후 3초 내 결과 공유 루틴 가동.

### [2단계] 월간 목표 및 선행지표 Action KPI 측정 (Mid-term / ~2주)
*새 테이블/마이그레이션 없이 기존 `workspaces.meta`를 활용한 결과 가시화*

1. **월간 목표(月) 설정 가드레일**
   - 월간 딜 클로징 목표, 핵심 프로젝트 마일스톤, 콘텐츠 큐 목표를 간단히 저장하고 첫 화면 상단에서 진행 게이지로 표시.
2. **Action KPI 4대 지표 자동 산출**
   - ① **Top 3 완료율**: 주간 기준 80% 이상 유지 여부.
   - ② **주간 고객 접촉 수**: 최소 15건 이상 접촉 달성 여부.
   - ③ **미결 안건(Open Issues) 전환율**: 메모/회의에서 나온 미결 안건이 실제 할 일로 전환된 비율.
   - ④ **누락 제로 검증**: 기한 초과(Overdue) 방치 건수 0건 유지.

### [3단계] 신경망 자율 어드바이저 및 자동화 (Long-term / 30일 이후)
*실제 데이터가 누적된 후 정밀 고도화*

1. **주간 신경망 회고 자동 발행 (월요일 개인 / 목요일 회사)**
   - 지난 7일간의 메모, 미팅, 결정사항, 성과를 크론이 자동 취합하여 1페이지 종합 리포트 생성.
2. **모순/중복 방지 AI 어드바이저**
   - 새로운 기획이나 결정을 내릴 때 과거 3개월 내 메모/결정과 상충하는 점이 있으면 실시간 경고.
