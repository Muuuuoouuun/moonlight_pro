# 현금 흐름 — 한 줄 목록과 정렬

> 운영자 요청: UI/UX·정렬 개선, 한 줄로 표현할 수 있는 정보는 한 줄로.
> 관계: 같은 날 현금 흐름 기획의 첫 운영 UI 배치를 구체화한다. 계산·권한·수집 범위는 유지한다.

- 데스크톱: 제목·설명, 보기·필터, 합계의 라벨·값을 같은 행에 둔다. 월별 소비와 머니 이동은 두 열로 비교한다.
- 거래: 날짜·거래·출처·목적·금액. 회사 청구: 날짜·거래·목적·신청·소비·승인·회수·잔액. 구독: 계약·자술·약정·다음 청구·목적·사용 근거. 상세 정보와 원문은 기존 편집 드로어에서 읽는다.
- 긴 제목/메모는 목록에서 말줄임하고 전체 문자열을 상세에서 읽는다. 미확인과 확인된 0을 구분한다.
- 헤더 정렬은 오름차순 → 내림차순 → 기본 순서. 미확인은 항상 마지막, 동률은 원래 순서. 숫자를 표시 문자열로 정렬하지 않는다.
- 900px 아래에서는 행 정보를 두세 줄로 재배치하고 가로 스크롤을 페이지에 만들지 않는다. 모바일 390px·44px 터치·16px 입력을 지킨다. 넓은 월별 표의 스크롤은 표 안에 한정한다.
- 새 메뉴·설정·CFO 패널을 본문에 추가하지 않는다. 반복 설명은 더보기로 보내고 각 보기에는 필요한 한 줄 안내만 남긴다.

## 검증

금액·날짜 정렬, null 마지막, 3단 토글을 단위 검사한다. 실제 수집 자료로 세 보기·검색·월 선택·편집 드로어·라이트/다크·390px를 확인한다. 금융 원문·가격·스크린샷은 저장소 밖에만 둔다.
