# 공개 AI 도구 7종에서 빌려 올 개념 — 반영 기획

> 상태: DRAFT · 권장 (2026-09-26). 운영자 확정 사항이 아니다. 아래 "결정 필요" 4건이 정해지면 해당 항목만 확정으로 바꾼다.
> 관계: [에이전트 계층 방향](2026-09-24-agent-layer-direction.md)(스킬은 로컬 실행·Moonlight는 요청서와 receipt만, 자동 실행은 범위 밖)과 [개인 사업 OKR·KPI](2026-09-24-personal-business-okr-kpi-design.md)(확정 12·KR4 — 10월은 Moonlight 포함 신규 개발 0건, 오퍼 3개의 역할 고정)을 전제로 한다. 두 문서의 결정을 바꾸지 않는다.
> 출처: 운영자가 공유한 Notion 글 "AI 회사 일곱 곳이 사내에서 쓰던 도구를 공짜로 풀었습니다". 저장소를 직접 열어 확인한 것은 OpenAI Symphony(`openai/symphony`, SPEC.md 포함), Anthropic 금융 플러그인(`anthropics/financial-services`), Qwen3-TTS(`QwenLM/Qwen3-TTS`) 세 곳이며 셋 다 Apache 2.0이다. 나머지 넷(X 추천 알고리즘, NVIDIA PersonaPlex, Cloudflare OS, Tencent Hunyuan3D-2)은 원문 설명에 기댄다.

## 1. 한 줄 요약

10월에는 개발 없이 **일하는 규칙 3개와 영업 도구 3개**만 바꾸고, Moonlight 기능은 11월에 **AI 비용 표시 → 검토 대기 모아 보기** 순서로 하나씩 연다.

## 2. 빌려 오는 개념과 출처

| 개념 | 출처 | Moonlight에 이미 있는 것 | 빠진 것 |
|---|---|---|---|
| 감독 대신 검토 — AI가 끝낸 일은 "완료"가 아니라 사람 검토에서 멈춘다 | Symphony SPEC §1 handoff state | receipt가 할 일을 완료시키지 않는다 | "AI는 끝냈고 내가 볼 것"을 모아 보는 자리. 할 일 상태(inbox·todo·doing·blocked·done)에 대기가 없고, 스킬 요청서 목록 화면도 없다 |
| 작업마다 격리된 공간(동시 실행 수는 제한하지 않음) | Symphony SPEC §2.1·§4.1.4 | CLAUDE.md의 "여러 파일 작업은 전용 워크트리" | 공유 체크아웃을 한 세션만 쓰는 규칙. 2026-09-26 다른 세션이 공유 체크아웃의 브랜치를 바꿔 커밋이 다른 브랜치에 들어간 사고가 이 공백에서 났다 |

| 명령 한 줄 설치 묶음 | 금융 플러그인 마켓플레이스 | `npm run mcp:connect -- install` | 스킬 + MCP 연결을 한 번에 까는 묶음 |
| 명령과 참고의 구분 | 금융 플러그인 Skills vs Commands | — | AI 진입점마다 "부르면 결과가 나오는 명령"인지 "읽기만 하는 카드"인지의 기준 |
| 도입 사다리 — 시험판 → 내 일에 한 번 → 고객 일 | 원문 "어디부터 손대면 좋을까요" | 문서의 권장·확정 구분 | 새 도구·새 오퍼에 같은 사다리를 쓰는 규칙 |
| 실행마다 토큰 기록 | Symphony 세션 토큰 합계 | Office가 요청마다 토큰 합산(`apps/engine/lib/office/usage.ts`) | 월별 AI 비용 표시 — 프로필 §11 확정, 구현 0 |
| "원래 얼마 드나" — 대체 비용으로 값어치 보이기 | 원문 각 도구의 요금 비교 | — | 1:1 가격 제시에 쓰는 대체 비용 한 줄 |
| 무료 안내서 + 신청 링크 | 원문 글의 형식 자체 | — | AI 활용 실습 강의 모집 글 |

가져올 필요 없는 것: X 알고리즘의 "부정 반응은 점수를 깎고, 거를 것은 점수 전에 뺀다"는 구조는 `apps/hub/lib/sales-os/followup-scoring.js`에 이미 있다(무응답 −16·실패 −40, 기약 없음은 30일 제외). 금융 플러그인의 "초안까지만, 서명은 사람"은 Moonlight의 자동 발송 금지와 같다.

## 3. 10월 — 개발 없이 (KR4를 어기지 않는 범위)

Moonlight 코드와 새 기능은 건드리지 않는다. 규칙·로컬 설정·영업 자료만 바꾼다.

| # | 할 일 | 형태 | 성공 기준 |
|---|---|---|---|
| 10-1 | **체크아웃 하나에 세션 하나** — 세션 수는 제한하지 않는다(운영자 2026-09-26). 메인 체크아웃은 한 세션만 쓰고, 나머지 세션은 각자 워크트리에서 일한다. 커밋·push 직전 `git branch --show-current` 재확인 | 운영 규칙. 확정되면 CLAUDE.md·AGENTS.md "브랜치·Git 협업"에 한 줄씩 | 10월 한 달 동안 "브랜치가 발밑에서 바뀜"·"남의 미커밋 파일 휩쓸림" 0건 |
| 10-2 | **스킬 원본 하나** — `moonlight-skill-request`의 원본을 `.agents/skills/moonlight-skill-request/SKILL.md`로 옮기고 두 폴더는 링크로 잇는다 | 파일 이동·링크. 앱 코드 변경 없음 | 두 클라이언트가 같은 파일을 읽는다(`readlink`로 확인) |
| 10-3 | **종류별 증거 기준** — 스킬 파일에 표 하나를 더한다. 폴더 정리 = 작업 기록 파일 + 옮긴·휴지통·건너뛴 개수, 영수증 정리 = 합계표 파일 + 건수·합계 금액, 그 밖 = 결과 파일 경로 1개 이상(결정 B) | 스킬 문서 수정 | 월요일 이후 첫 receipt 3건이 기준을 지킨다 |
| 10-4 | **도입 사다리** — 새 도구·새 오퍼는 시험판 → 내 일에 한 번 → 고객 일 순서로만. 사다리를 건너뛰면 그 주 회고에 적는다 | 운영 규칙 | 10월에 사다리 없이 들인 도구 0 |
| 10-5 | **견적에 대체 비용 한 줄** — 1:1 가격 제시 때 "같은 일을 외주·구독으로 하면 얼마"를 한 줄 붙인다 | 영업 문구 | KR2 가격 제시 6건 중 절반 이상에 붙는다 |
| 10-6 | **무료 안내서 + 신청 링크** — 직접 돌려 본 도구 하나(권장: 설치 없이 되는 Qwen 음성 웹 시험판 또는 Claude Code 금융 플러그인)로 안내서를 쓰고 끝에 강의 신청 링크 | 모집 글. 원문을 옮기지 않는다 | 10월 9일 모집 마감 전 공개 |
| 10-7 | **설치 없이 먼저 보기** — 학원용 소프트웨어 2종은 샘플 결과물(파싱된 문항 이미지, OMR 채점표)로 먼저 보여 준다 | 영업 자료. 추가 개발 금지(확정 13) 그대로 | KR3 고객 대화에서 샘플을 쓴다 |

## 4. 11월 — Moonlight 후보 (동결 해제 뒤 한 번에 하나)

표면 예산 규칙을 지킨다. 새 패널·버튼을 덧붙이지 않고, 기존 화면 안에 넣거나 하나를 빼고 넣는다.

| 순서 | 후보 | 이유 | 범위 |
|---|---|---|---|
| 11-1 | **월별 AI 비용 표시** | 프로필 §11에서 이미 확정된 기능이고, 9/28부터 스킬이 Gemini 키를 쓰면 가장 먼저 필요하다 | Engine의 Gemini 호출은 모두 `apps/engine/lib/gemini.ts` 한 곳을 지나고 여러 라우트가 토큰 수를 이미 읽지만 저장하지 않는다. 새 기록 테이블(마이그레이션 0052 이후 번호) + 한 지점 기록 + 월 합계 표시. 운영자 Mac의 로컬 스킬이 부르는 Gemini는 Moonlight를 거치지 않아 여기 잡히지 않는다 — Google AI Studio 사용량 화면이 그 몫을 본다. 10월에 당길지는 결정 C |
| 11-2 | **검토 대기 모아 보기** | "AI는 끝냈고 내가 볼 것"이 지금 어디에도 모이지 않는다 | receipt 완료 + 할 일 미완료인 요청서를 오늘 화면과 Office 하단 7일 요약 두 곳에 같은 묶음으로(결정 D, 운영자 2026-09-26). 두 곳 모두 기존 목록 안에 넣고 새 패널을 만들지 않는다. 할 일 상태를 새로 만들지 않는다 |
| 11-3 | **AI 진입점 분류 기준** | 방향 문서 §5가 11월 진입점 정리를 예고했다 | 입구마다 "명령"(부르면 결과) 또는 "카드"(읽기만)로 나누고 둘 다 아닌 입구를 없앤다. 코드보다 목록 정리가 먼저 |
| 11-4 | **스킬·MCP 설치 묶음** | 새 기기·수강생 배포를 한 줄로 | Claude Code 플러그인 형식. Codex는 10-2의 링크 방식 유지 |
| 보류 | 로컬 음성(Qwen3-TTS) | 대본 속 고객 이름이 밖으로 나가지 않는 장점이 있지만 이 Mac에서 미검증 | 영상 대행 의뢰가 실제로 들어올 때만 시험판부터 |

## 5. 하지 않는 것

- 보드를 스스로 읽고 에이전트를 자동으로 돌리는 Symphony식 상시 실행 — 방향 문서의 "자동 스킬 실행은 범위 밖"과 충돌한다. 들이려면 별도 결정.
- 원문이 제안하는 새 오퍼(개발 대행, X 계정 대행, AI 전화 안내 등) — 10월 오퍼 3개의 역할과 충돌한다. 강의 소재로만 쓴다.
- X 알고리즘 기준으로 Studio 편집 기준을 바꾸는 것 — 연결된 채널은 인스타그램·스레드·유튜브다.
- NVIDIA PersonaPlex — 원문 기준 NVIDIA 그래픽카드와 리눅스가 필요한데 이 Mac은 Apple 칩(arm64)이다. AI가 고객에게 직접 말하는 구조도 "밖으로 보내지 않는다"와 충돌한다.
- Cloudflare OS식 즉석 앱 — 표면 예산 원칙과 반대 방향이다.
- Tencent Hunyuan3D-2 상업 사용 — 원문 기준 약관이 한국을 제외한다.
