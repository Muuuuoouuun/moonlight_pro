# 실사용 입력 개선

> 상태: 승인·구현(2026-09-20). 운영자의 “굿 진행”에 따라 실행. 태그 검색0035 서울 DB 적용 완료; 앱 배포는 별도.
> 관계: DESIGN.md의 compact Drawer·저장 신뢰 계약, 기존 메모·PMS 기록을 유지한다. 새 생성 표면의 중앙 팝업과 PMS 분류 패널의 메뉴 전환을 보강한다.

## 승인 범위
- 체크리스트를 체크박스·제목·추가 액션 한 줄로 표시하고 메모는 선택 펼침으로 둔다.
- Enter는 현재 항목 다음에 새 항목을 넣고 포커스한다. 빈 제목·IME 조합·저장 중·50개 제한에서는 추가하지 않는다. 새 빈 줄 즉시 오류 표시는 피한다.
- 할 일 생성은 compact Drawer, 상세 편집은 side Drawer. 상태·우선순위·기한을 짧게, 부가 설명은 선택 펼침으로 표시한다. 저장 성공 후에만 닫거나 연속 입력을 초기화한다.
- 메모는 원문 먼저 저장하며 프로젝트·고객·브랜드 연결을 가까이 노출한다. 자유 태그는 선택 입력이며 기존 원문·충돌·복구·활용 계약을 유지한다. 태그 저장과 검색을 함께 연결한다.
- PMS 분류 패널은 상단의 작은 소속 선택 메뉴로 옮긴다. 생성·편집·숨긴 컨테이너·필터 기능을 계속 사용할 수 있다. 반복 설명 범례는 항목 직접 라벨로 대체한다.
- 태그와 소속은 별개다. 임의의 하위 프로젝트 데이터 계층을 신설하지 않고 기존 프로젝트/브랜드 연결을 재사용한다.

## 검증과 실사용 체크
- 저장 실패 시 입력 보존, 재시도 중복 방지, 새로고침 후 값 유지.
- 한글 IME Enter, 빈 줄 연속 추가 방지, 체크리스트 이동·삭제·되돌리기.
- 모바일 터치 타깃·긴 제목·키보드 가림·포커스 복귀.
- 소속 변경 뒤 현재 필터 밖에 저장된 항목, 검색·스크롤 복귀, 다중 창 충돌.
- 일괄 변경과 모든 입력창 초안 복구의 확대는 현재 지원 상태를 확인해 별도 실사용 백로그로 기록한다.
