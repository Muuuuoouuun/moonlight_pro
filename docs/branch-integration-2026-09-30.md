## 검토에서 수정한 회귀

- Mac 빠른 패널을 오른쪽 끝에 놓고 재열기할 때 412pt 왼쪽으로 밀렸다. 펫과 패널의 방향·간격을 저장하고 기존 위치 JSON과 호환되게 복원한다.
- 같은 제품 페이지에서 New → 닫기 → New를 실행하면 두 번째 드로어가 열리지 않았다. URL의 생성 쿼리를 소비한 뒤 다시 받을 수 있게 한다.
- 저장된 제품 생성 요청의 재전송에도 새 집중 진입 상한이 적용됐다. 같은 ID의 영수증·payload를 먼저 확인하고 새 제품만 상한을 검사한다.
- AI 훅 후보가 첫 장면의 시간을 바꿔도 통과했다. 모든 장면 ID·시간과 뒤 장면 내용을 보존하며 JSON 키 순서만 달라진 후보는 허용한다.
- 후속편 생성의 연속 클릭·응답 유실 재시도가 다른 새 글을 만들 수 있었다. 현재 열린 발행 로그 안에서 동일 요청 ID·본문을 재사용하고 확인된 새 글로 이동한다.
- 후속편 제목·본문의 길이 제한 경계에서 이모지가 잘려 유효하지 않은 Unicode가 만들어졌다. 잘림 경계의 surrogate pair를 보존해 저장 명령이 깨지지 않게 한다.

각 문제의 수정 전 실패를 재현하고 회귀 검증을 추가했다. 기능별 수정은 독립 커밋으로 보존했다.
