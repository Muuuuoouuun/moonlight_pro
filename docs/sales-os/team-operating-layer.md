## 2. 5 페르소나 (7 → 5 통폐합)

| # | 페르소나 | 역할 | 비고 |
|---|----------|------|------|
| ① | **오더** | 신호 읽고 작업지시서 + 360 조립 + 활성 페르소나 선택 | 지휘 두뇌 |
| ② | **세일즈** | 딜 다음수 · 반론 · **팔로업**(최대 잡무) | 전환 엔진 |
| ③ | **콘텐츠** | 아이디어 큐 · 발행 케이던스 · 앵글 | 작성 대행 아님 |
| ④ | **제작** | 승인 앵글 → 채널 포맷 골격 | 발행 마찰 제거 |
| ⑤ | **검수** | 브랜드·사실 셀프리뷰 → Codex 게이트 | 브랜딩 흡수 |

**흡수된 것:** 마케팅 = 오더 트리아지 + 콘텐츠 `social_signals` 반영(전용 광고는 vNext). 브랜딩 = 검수 일관성 + 콘텐츠/제작 가드레일.

**통폐합 근거(확정 사실):** 최대 잡무 = 팔로업 → 세일즈 1순위. 콘텐츠 병목 = 소재/아이디어 + 발행 꾸준함이지 초안·디자인 아님 → 콘텐츠는 아이디어·케이던스, 제작은 "작성"이 아니라 마찰 제거.

- `/morning`(2팀 빠른 루프)은 그대로. `/team`은 풀 5-페르소나 루프 — 신규.

## 5. 롤아웃

1. **Phase 1 (지금):** 지침·스파인·커맨드 작성·커밋. `/team` 온디맨드 수동.
2. **Phase 2:** 360 조립기 코드 모듈 + registry 로더 빌드(별도). 선택 활성화 자동.
3. **Phase 3:** Hub `agents.jsx`를 `registry.json`·최근 루프 결과로 실데이터 배선.
4. **Phase 4:** 4주 안정 + 측정 성과 낸 플레이만 moonlight Engine/Hub 코드로 졸업.

## 6. 첫 실행 (Assignment)

내일 아침 `/team 1` — 정체 딜 1건으로 끝-to-끝: 오더 360 조립 → 세일즈 next-action+팔로업 →
(반론 자료 필요시) 콘텐츠·제작 → 검수·Codex → 큐 초안. 한 항목이 게이트까지 흐르는지 확인.
콘텐츠 랭킹 부트스트랩용 The Assignment(반응 좋은 글 3 + 안 좋은 글 2)도 함께.
