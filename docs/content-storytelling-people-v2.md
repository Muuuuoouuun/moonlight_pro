# PART 0. 읽는 법 — 증거 등급과 4개의 심리학 렌즈

## 0-1. 왜 심리학을 붙이는가

크리에이터들의 프레임워크는 대부분 **"해보니 됐다"의 귀납**이다. 사후 설명력은 높고 사전 예측력은 낮다(v1에서 Kallaway 항목에 지적한 그 문제). 심리학을 붙이는 이유는 딱 하나 — **왜 되는지를 알면, 되는 조건과 안 되는 조건을 구분할 수 있다.** 한국 학원 시장에 미국 숏폼 문법을 그대로 옮기면 실패하는 지점이 정확히 "기제는 같은데 조건이 다른" 지점이다.

## 0-2. 증거 등급 (이 문서 전체에 적용)

| 등급 | 기준 | 취급 |
|---|---|---|
| **A** | 다수 반복 검증 + 메타분석 존재. 효과 방향에 학계 합의 | 설계의 기본 가정으로 사용 |
| **B** | 잘 인용된 단일·소수 연구. 방향은 안정적이나 효과 크기는 맥락 의존 | 가설로 사용, 자체 A/B로 확인 |
| **C** | 대중서·강연 기원, 또는 재현 실패/논쟁 중 | 은유로만 사용. 설계 근거로 쓰지 않음 |

> 재현 위기(2010년대 이후 사회심리학의 대규모 재현 실패)를 감안해 **프라이밍·자아고갈·파워포즈 계열은 전부 C**로 분류했다. 콘텐츠 업계가 즐겨 쓰는 "옥시토신 스토리텔링"(Paul Zak)도 C.

## 0-3. 4개의 렌즈

| 렌즈 | 묻는 것 | 대표 개념 |
|---|---|---|
| **인지심리학** | 뇌가 정보를 어떻게 걸러내고, 붙잡고, 기억하는가 | 주의·작업기억·정보격차·처리유창성·기억 인출 |
| **행동심리학 / 행동경제학** | 사람이 실제로 무엇을 선택하고 반복하는가 | 손실회피·보상예측오차·변동보상·실행의도·현상유지 |
| **사회심리학** | 타인과 집단이 판단을 어떻게 바꾸는가 | 사회적 증거·기술적 규범·상호성·정교화 가능성·저항 |
| **과학적 접근 (측정)** | 어떻게 틀렸음을 알 수 있는가 | 생존분석으로서의 리텐션, A/B 설계, 표본 크기, 효과 크기 |

## 0-4. 이 문서의 기본 모델 — 콘텐츠는 5단계 심리 파이프라인이다

```
주목(Attention) → 유지(Retention) → 기억(Encoding) → 행동(Action) → 전파(Transmission)
```

10인 각각은 이 5단계 중 **특정 단계의 전문가**다. Kallaway·Brendan Kane·MrBeast는 주목·유지, Harry Dry·Nathan Baugh는 기억, Hormozi·Dan Koe는 행동, Justin Welsh·Colin & Samir는 전파와 시스템. 이 좌표를 알면 누구 말을 어디에 쓸지 결정된다.

## 01. Kane Kallaway — "숏폼은 예술이 아니라 역설계 가능한 시스템"

### ① 좌표
| 항목 | 내용 |
|---|---|
| 정체 | 前 경영 컨설턴트(7년) → 숏폼 크리에이터 → SaaS 창업자 |
| 규모 | 3개 플랫폼 합산 팔로워 약 130만. 최고 조회 틱톡 1,130만 뷰 / 130만 좋아요 |
| 사업 | **sandcastles.ai** (유저 4.3만+, 유료광고 0, 출시 이래 흑자) + **The Academy** (유료 코호트 = 수익 + SW 베타테스트 풀) |
| 수익 | 월 순익 6자리(자기보고). 2024년 10월 약 $24K → 14개월 만에 4배. 10년 내 월 $1M 목표 |
| 실패 이력 | 팟캐스트·웰니스 미디어·의류·크립토 4연속 실패 → 전부 **"유통 부재"** 로 단일 진단 |
| 채널 선택 논리 | 테크 숏폼(브랜드 딜이 큰 분야)으로 시작 → 자기 제품 런칭용 오디언스로 피벗 |

### ② 핵심 주장
1. **콘텐츠 이전에 유통.** 제품이 나빠서 죽은 게 아니라 사람이 없어서 죽었다. 오디언스 퍼스트.
2. **숏폼을 고른 이유는 도달이 아니라 학습 속도.** 롱폼 1편 30시간 vs 숏폼 2시간 → 같은 기간에 15배 실험. 숏폼 = 가설 검증 단위.
3. **훅은 재능이 아니라 데이터.** 성과 영상을 전사해 훅·구조를 추출하면 패턴이 나온다 → 그 확신을 SaaS로 만듦.
4. **주목은 한 번 사는 게 아니라 계속 재구매한다.** 오프닝 훅 1개가 아니라 본문 내내 재훅.
5. **숏폼은 전환 장치가 아니다.** 전환은 누적 시청 시간이 만든다.
6. **입력을 줄여야 출력이 는다.** 30개 사이트 대신 뉴스레터 10~12개.

### ③ 프레임워크 상세

**(1) 바이럴 6요소**

| # | 요소 | 판정 질문 | 실행 규칙 |
|---|---|---|---|
| 1 | 아이디어 타이밍 | 이 주제, 내가 몇 번째인가? | 흔한 주제는 *가장 먼저*. 늦었으면 *흔치 않은 앵글*. 소스는 대형 매체가 아니라 니치 블로그·소형 채널·업계 뉴스레터 |
| 2 | 큰 적용 모집단 | 이 얘기가 몇 명에게 '내 얘기'인가? | "희귀한 아이디어 × 큰 모집단". 하나만 크면 실패 |
| 3 | 고유 POV | 이 문장을 다른 사람도 쓸 수 있나? | 사실 전달이 아니라 해석·입장·판정 |
| 4 | 월드클래스 훅 | 시각·음성·텍스트가 같은 말을 하는가? | **3중 훅 정렬.** 도입부와 본문의 약속이 이어지는지 확인. 제작시간 **80%**는 검증되지 않은 경험칙 |
| 5 | 스토리 구조 | 긴장이 몇 번 갱신되는가? | 맥락 → 갈등 → 재훅 → 해소의 교대 |
| 6 | 운 | 시도 횟수가 충분한가? | "Luck favors volume" |

**(2) 스크립트 구조 — Hook / Dance / Rehook / Final Hook**

| 구간 | 기능 | 설계 지침 | 실패 신호 |
|---|---|---|---|
| Hook | 첫 궁금증 루프 오픈 | "정신적 가려움(mental itch)"을 만든다 | 첫 문장이 배경 설명 |
| Dance | 맥락↔갈등 교대 | 한 박자마다 상태가 바뀌어야 함 | 정보 나열, 리스트 읽기 |
| Rehook | 루프 재오픈 | "Set up, rehook. Set up, rehook." | 중반 이탈 절벽 |
| Final Hook | 공유 유발 | 남에게 전달할 이유를 준다 | "구독 좋아요" 마무리 |

**(3) Content Minutes — 검증 전 가설**

| 항목 | 취급 |
|---|---|
| 누적 시청 **90분** | 원문·적용 범위·전환 효과가 검증되지 않은 경험칙. 목표치로 사용하지 않는다 |
| 숏폼과 롱폼의 역할 | 유입과 관계 형성의 형식별 차이를 관찰하는 가설. 형식만으로 매출·전환을 단정하지 않는다 |
| 적용 | 실제 채널의 재방문·완독·문의 데이터를 확인한 뒤 형식과 빈도를 조정한다 |

**(4) 리듬 규칙** — 문장 길이 변주(짧-중-긴) / 플랫폼 네이티브 호흡 / 입력 소스 압축

### ④ 출처 문구 점검

[Kallaway 인터뷰 공개 소개](https://podcasts.apple.com/us/podcast/rhythm-hooks-and-a-billion-views-kane-kallaways/id1727260996?i=1000666890786)에서 기존 요약의 개별 영문 문구와 발언 맥락을 확인하지 못했다. 확인 전에는 직접 인용으로 재사용하지 않는다. 도입부 제작시간 80%는 효과가 입증된 배분 규칙이 아니다.

### ⑤ 심리 기제 분해

| 프레임워크 요소 | 작동 기제 | 근거 연구 | 등급 | 설명 |
|---|---|---|---|---|
| Hook = "정신적 가려움" | **정보 격차(Information Gap) 이론** | Loewenstein (1994) | A | 호기심은 "아는 것"과 "알고 싶은 것" 사이의 격차를 인지할 때 생기는 **박탈감**. 격차가 너무 작으면(다 아는 얘기) 무관심, 너무 크면(전혀 모르는 분야) 포기. 훅은 격차를 **적정 크기로 여는 행위** |
| Rehook 반복 | **자이가르닉 효과** (미완 과제의 기억 우위) | Zeigarnik (1927); 후속 재현은 혼재 | B | 미완결 과제는 완결된 과제보다 기억에 오래 남고 인지적 긴장을 유지. 재현 결과가 일관되지 않아 B. 다만 "오픈 루프가 이탈을 줄인다"는 현상 자체는 리텐션 데이터로 채널마다 확인 가능 |
| 3중 훅 정렬 (시각·음성·텍스트) | **이중 부호화 이론 + 다중감각 중복 효과** | Paivio (1971, 1986); Mayer 멀티미디어 학습 원리 | A | 언어 채널과 시각 채널이 **같은 메시지**를 전달하면 부호화가 강화되고, **다른 메시지**를 전달하면 작업기억이 분산되어 처리 실패(Mayer의 일관성 원리). "정렬"이 핵심인 이유 |
| 도입부 제작시간의 80% 배분 | **초두 효과 + 선택적 주의**는 관련 개념일 뿐 해당 배분을 검증하지 않음 | Murdock (1962) 계열위치효과; Broadbent 필터 모델 | **C (80% 수치)** | 도입부의 중요성을 검토할 수는 있지만, 제작시간의 고정 비율을 정당화하지 못한다. 채널별 이탈·완독 데이터를 보고 배분을 조정한다 |
| 문장 길이 변주 | **정향 반응(Orienting Response)과 습관화** | Sokolov (1963) | A | 자극이 일정하면 신경계는 빠르게 습관화(habituation)해 주의를 거둔다. 리듬 변화는 새 자극으로 등록되어 정향 반응을 재유발. "내용이 아니라 길이가 지루하게 만든다"의 정체 |
| Content Minutes 90분 | **단순 노출 효과 + 처리 유창성** | Zajonc (1968); Reber, Winkielman & Schwarz (1998) | A(기제) / C(90분이라는 상수) | 반복 노출은 호감을 올리고(단순 노출), 익숙한 것은 더 쉽게 처리되어 "옳다/좋다"로 느껴진다(유창성). 기제는 A급이지만 **90분이라는 수치는 근거 없는 경험칙** |
| "희귀 아이디어 × 큰 모집단" | **자기 관련성 효과(Self-reference effect)** | Rogers, Kuiper & Kirker (1977) | A | 자기와 관련지어 처리한 정보는 기억이 월등히 좋다. "큰 모집단"은 자기 관련성을 느낄 사람의 수, "희귀"는 그 안에서의 정보 격차 |
| 아이디어 타이밍(가장 먼저) | **초기 진입자 우위 + 가용성 휴리스틱** | Tversky & Kahneman (1973) | B | 처음 접한 프레임이 이후 판단의 기준(anchor)이 됨. 같은 얘기를 두 번째로 하면 "이미 본 것"으로 분류되어 정향 반응이 안 일어남 |
| "Luck favors volume" | **대수의 법칙 + 멱함수 분포** | 통계학 일반; Salganik, Dodds & Watts (2006) 음악 실험 | A | Salganik 실험: 같은 곡이라도 사회적 영향이 있는 시장에서는 **어떤 곡이 히트할지 예측 불가**, 품질은 히트의 필요조건이지 충분조건이 아님. 예측 불가능하면 시도 횟수가 유일한 통제 변수 |

### ⑥ 한계·반론
- 규모·수익은 인터뷰 자기보고
- 6요소 중 4개가 '아이디어 선택'인데 선택법 자체는 경험치 의존 → 사후 설명력 高, 사전 예측력 低
- Content Minutes의 90분은 회계 픽션. 구조(유입/전환 분리)만 가져올 것
- 자이가르닉 효과 재현 불안정 → "오픈 루프"는 심리학 이론이 아니라 **자체 리텐션 데이터**로 정당화해야 함

### ⑦ 반증 가능한 실험 설계 (우리 맥락)
| 가설 | 설계 | 지표 | 기각 조건 |
|---|---|---|---|
| H1: 재훅이 있는 세미나가 이탈이 적다 | 같은 세미나를 재훅 3개 삽입 버전 / 미삽입 버전으로 2회 진행 | 7·15·25분 지점 잔존율 | 잔존율 차이 < 5%p |
| H2: 3중 정렬 훅이 클릭을 올린다 | 카드뉴스 1장에서 이미지·헤드라인 메시지 일치 vs 불일치 | 클릭률(CTR) | 차이 없음 |
| H3: 롱폼 노출 없이 숏폼만 본 원장은 전환 안 됨 | 3개월 후 리드 소스별 미팅 전환율 비교 | 숏폼 단독 노출군 vs 세미나 참석군 | 두 집단 전환율 동일 |

### ⑧ 학원 B2B 전환 — 관통법칙 #1(구조) · #3(시스템)
- 숏폼 편수 공식 대신 실제 목표와 제작 여력에서 형식을 역산한다

## 02. Alex Hormozi — "콘텐츠는 작품이 아니라 광고 자산이다"

### ② 핵심 주장
1. 콘텐츠는 **리드 확보 4개 경로 중 하나일 뿐**. 콘텐츠만 하는 건 전략이 아니라 회피.
2. 콘텐츠 단위는 길이가 아니라 **초당 가치(value per second)**.
3. **공짜가 유료보다 좋아 보여야 한다.** 안 산 사람도 추천하게 만드는 게 리드마그넷의 목적.
4. **일관성 > 복잡성.** Rule of 100.
5. **새 채널로 도망치지 마라.** More → Better → New.
6. **획득비용은 30일 안에 회수**(Money Models). 그러면 볼륨은 더 이상 자금 문제가 아님.

### ③ 프레임워크 상세

**(1) Hook / Retain / Reward**

| Retain | 이탈 방지, 모멘텀 유지 | 오픈 루프, 군더더기 제거, 잦은 컷, 통증 직격 | "서론이 길다" |
| Reward | 주목에 대한 보상 | 즉시 실행 가능한 테이크어웨이, 과잉 전달, 마찰 없는 자료 | 다 보고 나서 할 게 없음 |

**(2) Core Four**

**(4) 리드마그넷** — "리드가 안 나오면, 끝내주는 리드마그넷을 만들어라." 판정: 안 사더라도 추천하는가.

| Retain = 군더더기 제거 | **인지 부하 이론** | Sweller (1988) | A | 작업기억 용량은 극히 제한적(Cowan 2001: 약 4청크). 외재적 부하(불필요한 정보)가 본질적 처리를 밀어냄. "초당 가치"는 인지부하 이론의 다른 표현 |
| Upsell / Continuity | **일관성 동기 + 현상유지 편향** | Cialdini 일관성; Samuelson & Zeckhauser (1988) | A | 한번 "예"라고 한 사람은 그 결정과 일치하는 다음 결정을 하려는 압력을 받음. 구독은 기본값(default)이 되면 해지에 행동 비용이 붙어 유지됨 |
| Downsell | **대비 효과 + 문간에 얼굴 들이밀기(DITF)** | Cialdini et al. (1975) | A | 큰 요청 거절 후 작은 요청은 수락률 상승(양보의 상호성) |

|---|---|---|---|---|
| Familiar but Unexpected | **최적 각성 / 분트 곡선 + MAYA** | Berlyne (1960, 1971); Loewy "Most Advanced Yet Acceptable" | A(Berlyne) / B(MAYA) | 선호는 새로움의 역U자 함수. 너무 익숙하면 지루, 너무 새로우면 불안·거부. 정점은 "익숙한 틀 안의 새로움". Hekkert et al. (2003)이 제품 디자인에서 재현 |

| Ride it until they stop you | **반복 노출 + 시그니처 인식** | Zajonc; 관통법칙 #4 | A | 반복은 인지 비용을 0으로 만듦. 단 관통법칙 #4의 조건(형식 고정, 대상·문제 갱신)을 안 지키면 **과잉 노출 → 지루함(Berlyne 곡선의 하강)** |

### ⑤ 한계·반론

- "반복"이 관통법칙 #4와 결합 안 되면 동어 반복 붕괴 (2026 상반기 나영석·김태호 사례)
- Tiny Tweaks 40배 사례는 **생존자 편향** 가능성. 개선 → 증폭은 알고리즘이 그 개선을 "발견"할 때만

### ⑥ 반증 가능한 실험 설계
| 가설 | 설계 | 지표 | 기각 조건 |
|---|---|---|---|
| H1: 익숙한 포맷+비틀기 제목이 완전 새 제목보다 클릭 높다 | "학원 상담 매뉴얼: 전환율 55% 학원의 스크립트 전문" vs "AI 시대 상담의 재정의" | CTR | 동일 |
| H2: 기존 세그먼트 80% / 신규 20% 배분이 100/0보다 분기 리드 총량 높다 | 분기 콘텐츠 배분 다르게 | 분기 미팅 수 | 동일 이하 |

### ⑦ 학원 B2B 전환 — 관통법칙 #1 × #4

## 06. Nathan Baugh — "세계를 먼저 짓고, 이야기로 전달하라"

## 07. Harry Dry — "카피는 시각화·반증·독점이 되는가로만 판정한다"

### ① 좌표
- Marketing Examples 운영. 실제 브랜드 카피 사례를 수집·해부하는 방식. 이론가가 아니라 **판정 기준을 만든 사람**

### ④ 심리 기제 분해

| 요소 | 작동 기제 | 근거 연구 | 등급 | 설명 |
|---|---|---|---|---|
| 시각화되는가 | **구체성 효과 + 이중 부호화** | Paivio (1971); Sadoski & Paivio 구체어 기억 우위 | A | 구체어는 언어+심상 이중 부호화, 추상어는 언어만 → 구체어 기억 약 2배. "10분 안에"는 심상이 생기고 "더 나은"은 안 생김 |

| 고객이 쓴 것처럼 | **처리 유창성 + 자기 관련성** | 앞과 동일 | A | — |
| Proof Principle | **ELM 중심 경로 + 주장-증거 순서** | Petty & Cacioppo | A | 대담한 주장으로 관여도를 올린 뒤(중심 경로 진입) 증거를 제시해야 정교화가 일어남. 증거부터 나열하면 관여 전에 이탈 |

## 09. Dan Koe — "복리가 붙는 건 뷰가 아니라 메시지다"

### ① 좌표
- 1인 기업 모델 전도사. 뉴스레터 1개를 허브로 전 채널 운영

### ② 핵심 주장
1. **복리가 붙는 건 조회수가 아니라 메시지.** "메시지가 사람들 머릿속에서 복리로 쌓이다가 어느 순간 전체가 clicks 한다."
2. 개별 바이럴이 아니라 1~3개월의 일관된 출력이 권위를 만든다.
3. 타깃 아바타를 조사하지 말고 **네가 아바타가 되라.**
4. 니치 = 주제 3개의 고유한 조합.
5. 콘텐츠는 레버리지. 시간을 파는 일이 콘텐츠 시간을 잡아먹으면 끝.

### ③ 프레임워크 — 자기 제품화 4기둥
| 기둥 | 내용 |
|---|---|
| Branding | 목표와 원하는 결과 정의 |
| Content | 고유하게 교차하는 3개 관심사 |
| Offer | 최소 실행 오퍼 먼저(컨설팅 콜 $500~1,000) |
| Marketing | 오디언스 상호작용으로 지속 노출 |

### ④ 심리 기제 분해

| 메시지 복리 | **간격 반복 + 착각적 진실 효과** | Ebbinghaus (1885); Cepeda et al. (2006) 간격 효과 메타분석; Hasher et al. (1977) | A | 같은 메시지를 간격을 두고 반복 노출하면 기억 유지가 급증(간격 효과). 반복된 진술은 진실로 느껴짐(착각적 진실). "복리"의 정체는 이 둘 |

### ⑤ 한계·반론
- "2~4시간 근무 + 7자리" 서사는 생존 편향

- 착각적 진실 효과는 **거짓도 반복하면 진실로 느껴진다**는 뜻이므로 윤리 경계: 반복할 메시지는 참이어야 함

- 3주제 교집합: **에듀테크 × 학원 운영 실무 × B2B 세일즈** — 국내에 이 교집합 인물이 거의 없음

## B. 5단계 심리 파이프라인 — 기제 통합 지도

각 단계에서 **무엇이 병목이고, 어떤 기제가 병목을 푸는지**, 누구의 프레임을 쓰는지.

### B-1. 주목(Attention) — 병목: 선택적 주의의 게이트

## C. 서로 충돌하는 지점 — 심리학으로 판정

| 쟁점 | A 입장 | B 입장 | 심리학적 판정 |
|---|---|---|---|

# PART III. 한국 시장 문화심리 캘리브레이션

## A. 왜 미국 문법이 한국 학원 시장에서 그대로 안 되는가 — 기제는 같고 조건이 다르다

| 차원 | 미국 크리에이터 환경 | 한국 학원 원장 환경 | 조정 |
|---|---|---|---|
| **맥락 의존도** (Hall 고맥락/저맥락) | 저맥락: 명시적·직접적 메시지가 표준 | 고맥락: 말하지 않은 것(관계·평판·누가 소개했나)이 정보 | 직접 주장 ↓, **소개·사례·관계 신호** ↑ |
| **불확실성 회피** (Hofstede, 한국 높음) | 새로움 수용이 상대적으로 빠름 | 검증 안 된 것에 대한 회피 강함. "다른 학원은 쓰나요?"가 첫 질문 | **기술적 규범**("같은 지역 원장 N명이") 최우선 |
| **집단주의 / 준거집단** | 개인 판단 강조 | 원장 단톡방·지역 원장 모임이 판단의 준거 | 전파 단계를 개인 공유가 아니라 **단톡방 전달**로 설계 |
| **체면(face)** | 실패 공개가 콘텐츠 자산 | 실패 공개는 체면 손상 위험 → 사례 원장이 실명 공개를 꺼림 | 실패는 **익명·유형화**("○○동 180명 규모 학원")로, 성공은 실명으로 |
| **광고 회의론** | 높음 | 높음 + "업자" 프레임 즉시 발동 | 강한 주장 대신 **반증 가능한 숫자** |
| **권위 신호** | 개인 브랜드·팔로워 수 | 기관·레퍼런스·규모 | 팔로워 수보다 **도입 학원 수·지역** |
| **관계 선행** | 거래 후 관계 | 관계 후 거래 | 첫 접촉의 목적을 "판매"가 아니라 **"진단 제공"**으로 |

## B. 한국 시장에서 특히 강하게 작동하는 기제 3개

### B-1. 기술적 규범(Descriptive norm) — 가장 강한 레버
- Goldstein, Cialdini & Griskevicius (2008): 호텔 수건 재사용에서 "대부분의 투숙객이 재사용합니다"가 환경 보호 호소보다 효과적이었고, **"이 방에 묵었던 투숙객 대부분이"**(근접 규범)가 가장 강했다
- 불확실성 회피가 높은 집단에서 규범 정보의 가중치는 더 커진다
- **적용**: "같은 구, 같은 과목, 비슷한 규모의 학원 N곳이 이미"가 모든 메시지의 근접 규범 문장. 없는 숫자를 만들지 말고, **있는 숫자를 가장 근접한 단위로** 쪼갠다 (전국 → 서울 → 강남구 → 대치동 → 수학 → 150~200명)

### B-2. 손실 회피 × 체면 — 손실의 정의가 다르다
- 미국 훅의 손실은 돈("80% 낭비"). 한국 원장의 손실은 돈 + **평판**(학부모 사이의 소문, 실장 이탈, 옆 학원과의 비교)
- **적용**: 손실 프레임에 평판 차원을 넣는다 — "학부모가 먼저 아는 정보를 원장님이 제일 늦게 아는 구조"

### B-3. 상호성 — 관계 선행 문화에서 상호성은 더 오래, 더 강하게 작동
- 관계 선행 문화에서는 첫 호의가 "거래 준비"가 아니라 "관계 시작"으로 처리되어 상호성이 오래 유지됨. 단 호의가 영업 수단으로 드러나는 순간 배신감이 더 큼(체면 문화의 양날)
- **적용**: 진단 시트는 **영업 연락 없이도 완결된 가치**여야 함. 미팅 제안은 원장이 결과를 본 다음, 원장 쪽에서 질문이 나올 때

## C. 한국 시장에서 약하게 작동하거나 역효과인 기제

| 기제 | 이유 | 대체 |
|---|---|---|
| 기대 위반(충격 훅) | 화자 신뢰 부재 + 광고 회의론 → "업자" 분류 | 정밀 숫자(Zhang & Schwarz) + 3자 사례 |
| 개인 브랜드 유사성-호감 | 담당자 개인보다 회사·기관 신뢰가 우선 | 담당자 얼굴 + 회사 도입 실적 병기 |
| 비용 신호(wow factor) | 큰 예산 자체가 "우리 돈으로 광고하네"로 읽힐 수 있음 | 정보 비용 신호(공개하기 어려운 것 공개) |
| 직접 클로징 | 저항 + 체면(거절도 부담) | "사라고 말하지 않기" + 다음 행동을 **작게·구체적으로** |

## D. 원장 의사결정의 실제 경로 (ELM으로 재구성)

```
[단톡방/지인 언급] → 주변 경로 진입 (누가 쓰나, 평판)
        ↓
[진단 시트 / 세미나] → 관여도 상승 → 중심 경로 진입 (내 학원 숫자)
        ↓
[원장 인터뷰 / 실제 화면] → 서사 전송 (반박 감소) + 유추 (이해)
        ↓
[미팅: 원장 데이터로 같은 화면] → 자기 설득 (결론은 원장이)
        ↓
[실장·강사 설득 자료] → 다자 결정의 2차 중심 경로
```

→ 콘텐츠 자산은 이 경로의 **각 화살표마다 하나씩** 있어야 한다. 대부분의 B2B 콘텐츠는 2번째 칸(세미나)만 있고 1번째(규범 신호)와 5번째(내부 설득 자료)가 없다.

| 원장 사례 인터뷰 | 15~20분 | 기억 → 전파 | 근접 규범 + 유사성-호감 + 취약성 신뢰 | 월 1 |
| 운영 팁 롱폼 글 | 8~10분 읽기 | 기억 | 간격 반복(결론 문장 고정) + 구체성 | 주 1 |
| 숏폼/카드뉴스 | 30~60초 | **주목 전용** | 정보 격차 + 자기 관련성 | 주 3 |
| 1장 요약 이미지 | 즉시 | 전파 | 사회적 화폐 + 전달 비용 0 | 콘텐츠마다 |
| 진단 시트 | 10분 작성 | 행동 | 상호성 + 문간에 발 들이기 + IOED(스스로 문제 발견) | 상시 |
| 내부 설득 자료(실장·강사용) | 2장 | 행동(다자) | 2차 중심 경로 | 미팅 후 |

## D. 사내 실험 프로토콜 — "과학적 접근"의 최소 규격

### D-1. 원칙
1. **한 번에 한 변수.** 제목을 바꾸면 본문은 고정
2. **사전 등록.** 실험 전에 가설·지표·기각 조건을 문서에 적는다 (사후 해석 금지)
3. **표본 크기 감각.** 오픈율 20% 기준으로 5%p 차이를 보려면 집단당 대략 **수백 건** 필요. 리스트가 200명이면 A/B는 12주 누적으로만 의미 있음
4. **효과 크기 > 유의성.** 2%p 차이가 통계적으로 유의해도 실무적으로 무의미할 수 있음
5. **생존자 편향 경계.** "됐던 것"만 보지 말고 **안 됐던 것의 공통점**을 같이 기록

### D-2. 리텐션은 생존 분석이다
- 세미나·영상 잔존율 곡선을 **위험률(hazard)** 관점으로 읽는다: 어느 분에서 이탈이 가장 가파른가
- 가파른 구간 직전에 재참여 자극을 넣고, 다음 회차에서 그 구간의 기울기 변화를 본다
- 곡선이 "계단"이면 특정 자극 하나가 문제, "완만한 하강"이면 리듬(습관화) 문제

### D-3. 분기 실험 캘린더 (예시)

| 주차 | 실험 | 변수 | 지표 |
|---|---|---|---|
| 1–4 | 메일 제목 손실 vs 이득 | 제목 프레임 | 오픈·답장 |
| 5–8 | 진단 시트 vs 이북 | 리드마그넷 유형 | 다운로드→미팅 |
| 9–12 | 세미나 재참여 3개 vs 0개 | 자극 삽입 | 7·15·25분 잔존율 |
| 13 | 결과 리뷰 + 훅 DB 갱신 | — | — |

### D-4. 훅 데이터베이스 스키마 (Kallaway/sandcastles 방식의 사내 버전)

| 필드 | 예 |
|---|---|
| 훅 문장 | "상담 전환율 30%인 학원과 55%인 학원…" |
| 기제 태그 | [손실][격차] |
| 채널 | 메일 제목 / 카드뉴스 / 세미나 타이틀 |
| 원장 유형 | 숫자형 |
| 노출 수 / 반응 수 / 반응률 | 240 / 31 / 12.9% |
| 다음 행동 전환 | 미팅 4건 |
| 메모 | "강남 수학 세그먼트에서만 강함" |

→ 12주 후 이 표가 **우리 시장 전용 훅 이론**이 된다. 미국 크리에이터의 이론보다 이게 더 정확하다.

## E. 30 / 60 / 90일 실행 (기제 주석판)

**0–30일 — 입구 고정 (주목 단계)**
- 회사 훅 포인트 1문장 확정 (Brendan Kane) + 기존 문구 3질문 감사 (Dry) — *구체성·반증 가능성·독점성*
- 훅 40개 중 12개 실전 투입, 메일 제목 주 단위 A/B (Galloway) — *손실 vs 이득 프레임 검증*
- 리드마그넷 1종: 학원 운영 진단 시트 (Hormozi) — *상호성 + IOED*
- 근접 규범 문장 확정: "○○구 ○○과목 N곳" (Cialdini/Goldstein)

**31–60일 — 전환 장치 구축 (유지·기억·행동 단계)**
- 원장 세미나 1회, 잡스 7단계 스크립트 (Baugh) — *서사 전송 + 자기 설득*
- 7·15·25분 재참여 포인트, 자극 종류 다르게 (MrBeast) — *탈습관화*
- 원장 사례 인터뷰 1편, 실패 시기부터 (Colin & Samir, 관통법칙 #5) — *취약성 신뢰*
- 결론 문장 고정 시작: "감이 아니라 숫자로" (Koe) — *간격 반복*
- **66일 돌파**가 이 구간의 진짜 목표 (Lally 습관 형성 평균)

**61–90일 — 시스템화 (전파 단계 + 측정)**
- 주 3회 고정 발행 (Welsh) — *실행 의도 + 수용자 습관*
- 1장 요약 이미지 표준화, 단톡방 전달 추적 — *사회적 화폐*
- 훅 DB 12주 결과 리뷰 → 사내 훅 이론 v1 (Kallaway 방식)
- More → Better → New 판정: 채널 추가는 **여기서 처음** 검토 (Hormozi)
- 내부 설득 자료(실장·강사용) 제작 — *다자 결정의 2차 경로*
