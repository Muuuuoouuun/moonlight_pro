## 남은 확인 범위

- 세일즈 플레이북의 다른 인물별 인용문, 정확한 수치와 보편적 성과 표현은 원전 대조가 끝나지 않았다. 예를 들어 접촉 횟수별 계약률이나 특정 인물의 매출 효과를 카드로 옮기기 전에 개별 확인이 필요하다.
- 마케팅 문서의 약력·명언·“반드시”, “완전히” 같은 단정은 개별 확인 대상이다. 오길비의 인쇄 광고 관찰을 오늘의 채널 성과처럼 쓰지 않는다.
- 콘텐츠 문서의 심리학 연구에서 특정 제작 규칙으로 건너뛴 추론은 별도로 검증해야 한다. 문서의 A/B/C 등급은 해당 플랫폼·한국 학원 시장에서 효과가 확인됐다는 뜻이 아니다. `90분`, `80%`, `30%` 같은 크리에이터 경험칙은 효과 수치로 쓰지 않는다.
- Kallaway의 영상 재훅을 카드뉴스의 첫 장·본문 관계에 적용하는 것은 **Moonlight의 응용**이다. 원전이 카드뉴스 효과를 증명했다고 표기하지 않는다.

새 카드의 최소 검토 단위는 **한 주장 → 원전의 해당 절 → 이 제품의 적용 상황 → 적용하지 않을 상황**이다. 실제 고객의 반응·성과는 원장에 확인된 사실만 사용한다.
