# 보관과 재생성

이 폴더는 2026-09-20 최초 수집·선별 작업의 산출물 32개를 저장소에 보관한 것이다. 원 수집 스냅샷 17개와 인사이트·초안·통합 자료를 유지하고, 상대경로와 재생성·검증 도구를 보완했다. 앱 기능이나 운영 DB를 변경하는 도구는 포함하지 않는다.

## 실행

Python 3.9 이상과 표준 라이브러리만 사용한다. 네트워크, 계정 로그인, 설치된 앱, 기존 Documents 폴더, 최초 검토의 임시 원자료는 필요하지 않다.

저장소 루트에서:

```bash
python3 docs/research/2026-09-20-reference-writing/build-library.py
python3 docs/research/2026-09-20-reference-writing/verify-archive.py
```

`build-library.py`는 자신의 위치를 기준으로 `sources/youtube/`, `sources/instagram/`, `youtube-insights.json`, `instagram-insights.json`을 읽는다. `source-manifest.json`의 SHA-256을 먼저 확인한 뒤 `library.json`, `library.csv`, `library.md`, `coverage.json` 네 파일만 다시 쓴다. 원본 스냅샷을 다시 복사하거나 manifest의 해시를 자동 갱신하지 않는다.

`verify-archive.py`는 건수·중복·자료별 출처·필수 필드·확인 수준·CSV·로컬 링크·내부 스냅샷 해시를 확인한다. 별도 임시 폴더에 필요한 입력만 복사해 생성기를 다시 실행하고 네 산출물의 바이트 일치도 확인한다. 임시 폴더는 이 아카이브 내부에 만들고 자동 정리한다. 현재 외부 사이트의 접속 성공이나 원문 주장의 사실성은 검사하지 않는다.

폴더만 따로 가져간 경우에도 다음 명령으로 자료와 내부 링크를 검증할 수 있다. 이 옵션은 저장소 밖으로 향하는 코드·제품 문서 링크를 건너뛰었다고 명시한다.

```bash
python3 verify-archive.py --standalone
```

## 스냅샷과 검토 이력의 경계

- `sources/`의 17개 파일은 최초 보존본을 바이트 그대로 유지한다. 이 안의 당시 절대경로·다른 저장소 문서 링크·“이번 작업” 표현은 현재 상태로 다시 쓰지 않았다. 해시로 고정한 역사적 스냅샷이며 현재 안내는 이 파일과 상위 [README](README.md)를 따른다.
- 검증기는 스냅샷 내부의 같은 폴더 링크는 검사한다. 스냅샷이 가리키는 당시 외부 로컬 경로는 읽지 않으며 제외 건수를 보고한다. 이 예외는 `source-manifest.json`에 등록된 원본 파일에만 적용한다.
- 최상위 편집 문서는 내부 자료로 가는 상대경로를 사용한다. Moonlight 코드 근거는 저장소 기준 상대경로와 `#L행번호`를 사용한다. 코드 링크는 조사 시점의 근거이며 향후 코드 변경 시 줄 위치가 바뀔 수 있다.
- `source-manifest.json`의 `preserved_path`, `bytes`, `sha256`은 현재 내부 스냅샷의 검증 기준이다. `original_location_at_review`는 최초 파일 위치에 대한 이력일 뿐 접근 대상이 아니다.
- `evidence-manifest.json`과 YouTube 인사이트의 `original_location_at_review`는 최초 자막·영상 분석 응답의 위치 기록이다. 해당 파일의 당시 크기·해시를 보존했지만 **현재 원문 파일을 포함하거나 그 해시를 다시 검증한 것은 아니다.** 공개 영상 ID·URL·시점은 유지한다.

원 수집 자료와 함께 보관한 정지 이미지 1장은 기존 32개 파일에 있던 것이다. 원본 영상, 캡션 전문, 자막 전문, 추가 미디어는 이번 보관에서 복사하지 않았다.

## 보존한 자료 단위

통합 콘텐츠 370개와 원 목록 연결 401건·YouTube 중복 연결 31건을 유지한다. Threads 공유 프로필 2개와 프로필 분류용 발견 게시물 5개는 콘텐츠 370개에 합산하지 않는다. 선별 인사이트 26개 중 22개는 최초 작업에서 자막·캡션 구간을 대조했고, 4개는 기존 영상 분석 응답만 검토했다. 저장소 보관 자체가 추가 원문 검토나 사실 검증은 아니다.

YouTube 중복 영상의 통합 제목·태그는 최초 생성기와 같이 먼저 나타난 목록 행을 기준으로 한다. 다른 목록에서 관찰된 제목·태그와 각 순서는 `sources/youtube/coverage.json`에 그대로 남고, 통합 레코드의 `memberships`는 모든 목록 소속을 유지한다.
