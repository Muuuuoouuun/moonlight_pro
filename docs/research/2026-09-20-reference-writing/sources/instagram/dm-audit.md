## 중복·연결 후보

- **AI 회사 운영 스킬**: hongik.man과 leadgenman은 부서별 역할로 Claude를 운영한다는 주제가 가깝다. 원본이 같은 자료인지는 확인하지 않았다.
- **Claude 스킬 묶음**: ai_bombb의 ECC, moodmode.ai의 다섯 스킬 소개는 같은 ‘도구·스킬 라이브러리’에서 비교하기 좋다. 실제 기능·설치 안전성은 별도 검증이 필요하다.
- **영상 편집**: atlas.bennet 자료 2건은 서로 다른 게시물 URL이다. 하나에서 `clipzi.app` 문구를 확인했고, 다른 하나의 도구명은 확정하지 않았다.
- 수익·가격·별 개수·연구 통계는 **게시물의 주장**이며 이번 감사의 검증된 사실로 취급하지 않는다.

## 산출물과 수행 방식

- 구조화 자료: [dm-records.json](./dm-records.json)
- 모든 브라우저 조작은 `mcp__cua_repl`을 사용했다. 화면에 드러난 DOM/AX와 일부 영상 프레임만 읽었다.

- 원래 사용자 탭은 건드리지 않았다. 감사용 탭은 원래 DM으로 복귀시켰다.
