## 해석 기준

- **자막 기반 요약:** 확보한 자막을 읽고 한국어로 재서술했다. 자막이 영상 전체를 완벽히 담았다는 보장은 없다.
- **영상 직접 분석:** 자막 추출이 막히거나 품질이 부족해 Gemini API에 원본 공개 영상 URL을 입력했다. 응답의 VIDEO 입력 처리 기록을 확인했다. 자막 원문 확보와는 다른 상태다.
- **내용 미확보:** 제목·채널·링크만 기록했다. 제목만 보고 내용 요약을 만들지 않았다.
- **적용 제안:** 원문에 그대로 있는 지시가 아니라 내용을 활용하기 위한 편집 제안이다.
- 강연자의 연구·통계·건강·금융·심리 관련 주장은 별도로 검증하지 않았다. 발언자의 관점과 확인된 사실을 구분해서 읽어야 한다.
- 자동 자막의 오인식, 일부 자막만 제공되는 경우, 언어 불일치를 발견한 항목은 개별 정리에 표시했다.

## 확인 방법과 한계

재생목록별 서브에이전트 3개가 목록과 자막을 조사했다. 공개 HTML 조회와 로그인된 Chrome 목록을 대조했고, 자막 요청이 제한된 뒤에는 실제 ‘스크립트 표시’ 화면의 텍스트를 읽었다. 자동 내보내기의 ‘스크립트 없음’ 응답이 실제 UI와 다른 사례를 확인했으므로, 이를 곧바로 자막 미제공으로 해석하지 않았다.

Gemini가 내용별 요약·분류 초안을 생성했고, 일부 영상은 에이전트가 자막과 근거 시점을 대조했다. 모든 영상을 사람이 끝까지 시청한 검증 보고서는 아니다. 원문 전문·비밀번호·브라우저 쿠키·API 키는 결과물에 포함하지 않았다. 비공개 재생목록 정보는 외부 공개하지 않았고, Moonlight 운영 DB와 앱 코드도 변경하지 않았다.

자료를 한 가지 ‘성공 공식’으로 합치지는 않는 편이 좋다. 성공담, 학습 기법, 개인 경험, 종교적 해석은 근거의 성격이 다르다. 같은 실행 주제라도 자기를 강하게 몰아붙이는 조언과 지속 가능한 일정을 강조하는 조언은 적용 상황을 따로 기록해야 한다.

**가공 예시 — 아래는 원문 인용이 아니라 새로 만든 콘텐츠 기획안이다.**

- **「저장한 지식이 내 것이 되는 순간」**: 레퍼런스 하나를 쉬운 말로 설명하고, 막힌 부분을 다시 찾는 짧은 실험. 학습법 영상들을 소재로 삼는다.
- **「일정표를 채우기 전에 정할 것」**: 하루 핵심 과제와 원하는 하루의 모습을 먼저 정하는 글. 실행·일정 설계 자료를 연결한다.
- **「프로젝트 리뷰에서 먼저 꺼낼 이야기」**: 진척 숫자와 함께 막힌 점·도움이 필요한 점을 기록하는 체크리스트. 문제 파악 자료를 활용한다.

Moonlight에 연결한다면 이번 CSV의 영상 ID를 중복 키로 쓰고, 원본 링크·분류·요약 상태를 소재에 연결하면 된다. ‘자막 확보’, ‘영상 분석’, ‘내용 미확보’ 상태는 계속 보존해야 한다. 이번 작업에서는 운영 DB에 등록하지 않았다.
