## 1. politic_officer — 북핵 단계론에서 제안과 합의를 구분하기

**왜 골랐나:** 9월 22일 연설 이후 보도는 `단계적 비핵화`를 다시 전했다. 독자가 알아야 할 변화는 새로운 합의 성립이 아니라 정부가 공개적으로 제시한 접근 순서와 아직 비어 있는 협상 조건이다.

**확인한 사실**

- 9월 22일(뉴욕 현지시간) 이재명 대통령의 제81차 유엔총회 연설을 다룬 [연합뉴스 현장 보도](https://en.yna.co.kr/view/AEN20260923000851315)는 북미대화 재개 노력과 `핵·미사일 능력의 진전 중단 → 감축 → 비핵화`라는 단계적 방향을 전한다.
- 연설 전 [AP 서면 인터뷰 보도](https://apnews.com/article/koreas-lee-trump-kim-un-nuclear-2c12c8b88ca37e9dab861af584efa574)에서 대통령은 같은 단계론을 설명했다. AP는 단계별 양보 구상과 함께 북한의 대화 거부, 제재 완화만 얻고 핵 포기를 미룰 수 있다는 우려를 다뤘다.
- 이번 회차에서 북한·미국이 해당 단계와 검증 방식을 합의했다는 자료는 확인하지 못했다. AP 인터뷰와 연설 보도는 동일한 한국 정부 입장의 다른 전달 경로이므로 독립적인 정책 합의 두 건으로 세지 않는다.

**초안 — 검토 전**

> 북핵 문제를 두고 `중단 → 감축 → 비핵화`라는 단계적 접근이 다시 제시됐다. 이재명 대통령은 9월 22일 유엔총회 연설에서 북미대화 재개를 돕겠다는 뜻과 함께, 먼저 핵·미사일 능력의 확대를 멈추고 이후 감축을 거쳐 비핵화로 나아가는 방향을 설명했다.
>
> 여기서 구분할 것은 **접근안과 합의**다. 단계의 순서가 발표됐다고 해서 북한이 수용했거나, 각 단계의 검증 방식과 상응 조치가 정해진 것은 아니다. 실제 협상이 시작된다면 `무엇을 중단으로 인정할지`, `누가 이를 확인할지`, `어떤 조치를 서로 교환할지`가 핵심 쟁점이 된다. 지금은 제안된 방향을 이해하고, 다음 발표에서 이 조건들이 구체화되는지 살필 때다.

**미확인·보완:** 공식 연설 전문, 북·미 측의 이후 반응, 검증 주체와 상응 조치. 연설 전문이 공개되면 인용·표현을 원문과 대조한다. AP가 제기한 우려는 확정 결과가 아니라 위험 시나리오다.

## 2. 22th nomad — GPT-6 Sol·Luna, 이름보다 먼저 볼 선택 기준

**왜 골랐나:** 공급사가 9월 22일 두 모델을 발표하며 사용 가능 표면과 API 가격을 함께 제시했다. 초보자가 `신형 모델 출시`와 `내 계정에서 지금 보이는가`를 혼동하기 쉬운 소재다.

**확인한 사실**

- [OpenAI 공식 발표](https://openai.com/index/introducing-gpt-6-sol-and-luna/)는 GPT-6 Sol·Luna를 소개하고, API 모델 ID를 각각 `gpt-6-sol`, `gpt-6-luna`로 제시한다.
- 발표 시점의 API 표는 100만 입력/출력 토큰당 Sol **$2/$10**, Luna **$0.10/$0.50**이다. 이는 API 사용 가격이며 구독 요금이나 작업 한 건의 고정 비용이 아니다.
- 발표는 ChatGPT Work·Codex에서의 제공과 일반 ChatGPT의 단계적 배포를 구분한다. 공급사의 벤치마크 우위 주장은 이 회차에서 독립 재현하지 않았다.

**초안 — 검토 전**

> OpenAI가 9월 22일 GPT-6 Sol과 Luna를 발표했다. 새 이름 두 개를 외우기보다 **내가 할 일과 사용 경로**를 먼저 구분하면 이해가 쉽다. Sol은 복잡한 작업을 여러 번 다듬을 때, Luna는 가벼운 질문이나 반복 작업을 빠르게 처리할 때 살펴볼 만한 선택지다. 이 용도 구분은 발표 내용을 바탕으로 한 사용 제안이며, 실제 품질은 자신의 작업으로 비교해야 한다.
>
> 개발자는 API에서 두 모델을 선택할 수 있고, 발표 당시 입력·출력 토큰 가격도 각각 공개됐다. 다만 API 제공, Codex·ChatGPT Work 제공, 일반 ChatGPT 화면에서의 노출 시점은 서로 다르다. 메뉴에 아직 보이지 않는다면 `출시되지 않았다`고 단정하기 전에 사용 중인 제품과 계정의 제공 상태를 확인하자.

**미확인·보완:** 한국 계정의 실제 노출, 작업별 품질·속도 비교, 발표 후 가격 변경. 공급사 수치와 직접 시험 결과를 혼합하지 않는다. 후속 [프롬프트 캐싱 발표](https://openai.com/index/better-prompt-caching-for-gpt-6/)는 별도 소재로 분리한다.

## 3. class.moon — 유아 모집·반배정 평가, 10월 1일 전 점검할 것

**왜 골랐나:** 원장이 직접 운영 절차를 살펴야 할 수 있는 새 규정이다. 제목만으로는 예외적 진단의 조건과 시행일을 알 수 없어 첨부 개정안까지 확인했다.

**확인한 사실**

- [교육부 9월 22일 보도자료](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=107278&lev=0&m=020402&opType=N&page=1&s=moe&searchType=null&statusYN=W)와 [첨부 시행령 개정안 HWPX](https://www.moe.go.kr/boardCnts/fileDown.do?fileSeq=b3f8eb4ca9ed7a6ce162b5af8777651c&m=020402&s=moe)에 따르면 국무회의가 일부개정령안을 심의·의결했고, 부칙상 시행일은 **2026년 10월 1일**이다.
- 첨부 제11조는 유아를 모집하거나 수준별로 배정할 목적으로 하는 필기·구술·실기·면접 등 시험·평가와, 특정 능력 검증 결과 등을 활용한 평가 및 능력 수준을 서열화하는 평가를 금지 대상으로 적는다.
- 예외적 진단은 등록 또는 교습 시작 후, 교육활동 지원을 위한 관찰·면담 방식으로 진행하며 보호자에게 목적·방식·지원 내용을 알리고 서면 또는 전자적 사전 동의를 받아야 한다. 결과는 학습 진행·지원 필요사항을 서술하며 점수·순위·합격/불합격 표시를 하지 않는다.
- 교육부 발표는 유아 대상 개인과외교습자·교습소의 신고 의무와 위반 시 과태료 기준도 설명한다. 이는 모든 학원의 새 신고 의무라고 일반화하지 않는다.

**초안 — 검토 전**

> 유아 대상 학원을 운영한다면 10월 1일 전 **모집·반배정 평가와 등록 후 진단을 구분**해 볼 필요가 있다. 교육부는 9월 22일 관련 시행령 개정안의 국무회의 의결을 알렸다. 개정안은 유아를 뽑거나 수준별 반에 배정하기 위한 시험·평가의 범위를 구체화한다.
>
> 수업을 돕기 위한 진단은 조건이 다르다. 등록 또는 교습 시작 후 관찰·면담 방식으로 진행하고, 보호자에게 목적과 활용 방식을 알린 뒤 사전 동의를 받도록 했다. 결과를 점수·순위·합격 여부로 표시하지 않는 기준도 담겼다. 원장이라면 모집 안내문, 레벨 테스트, 진단 동의 절차, 결과표를 먼저 살펴보고 관할 교육청의 시행 안내와 최종 공포 문구를 다시 확인하는 것이 좋겠다.

**미확인·보완:** 최종 공포본과 관할 교육청의 세부 안내, 각 기관의 실제 운영 방식. 이 초안은 일반 정보이며 개별 기관의 법적 적용 판단을 대신하지 않는다. ClassIn 기능·효과·고객 사례는 이 자료에서 확인되지 않아 연결하지 않았다.

## 첫 수동 회차가 드러낸 설계 수정 후보

1. 교육부 페이지의 본문은 제목과 첨부 링크만 보여 줬다. 첨부 HWPX를 실제로 읽어야 시행일·예외·금지 범위를 확인할 수 있었다. 자동 수집기는 `본문 없음`과 `첨부에 본문 있음`을 다른 상태로 처리해야 한다.
2. 정치 사안은 인터뷰 직후 같은 주제의 유엔 연설이 나왔다. 사건 ID는 공유하되 `인터뷰 → 실제 연설`을 새 자료 버전으로 이어야 오래된 예정형 초안을 내지 않는다.
3. 신제품 발표의 `API 제공`, `특정 제품 제공`, `내 계정 노출`은 별도 상태다. 지역·계정별 실측 없이 전체 사용자에게 제공된다고 쓰지 않는다.

세 건 모두 운영자 검토 전이다. 킵은 이 버전의 자료·초안을 보관하고, 디벨롭은 지정한 관점으로 새 버전을 만들며, 완성은 근거와 원고를 다시 대조한 뒤 확정한다. 외부 발행과 정기 자동화는 이 기록으로 실행되지 않는다.
