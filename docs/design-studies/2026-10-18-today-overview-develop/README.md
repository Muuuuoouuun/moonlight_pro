## 오늘 — 3안
6c·6d에는 실제 오늘 화면의 1순위인 빠른 입력과 오늘 할 일이 없었다. 세 안 모두 그 둘을 첫 줄로 올렸다(`daily-brief.jsx` 슬롯 순서: 빠른 입력 → 오늘 할 일 → 긴급 KA·집중 고객·일정 → 신호). 확인할 것은 홈의 한 장씩 카드가 정본이라 오늘에는 맨 위 한 장만 둔다.

| 안 | 이름 | 요지 |
| --- | --- | --- |
| 7a | 실행 보드 (6c에서) | 빠른 입력 한 줄 + 할 일 · 연락할 사람 · 일정/작업 지시 세 칸. 운영 지표는 카드 4장 대신 한 줄 |
| 7b | 지금 → 다음 (6d에서) | 가로 하루 레일 + 선택한 일정의 맥락·준비할 것·기록, 빈 시간에 넣을 할 일(◇ 권장 → 넣으면 ● 확정) |
| 7g | 트리아지 + 멘토 한 줄 (홈 “5건 남았습니다”에서) | 왼쪽 확인할 것 목록 · 오른쪽 결정 카드 · 오늘의 시간표를 입체 패널 질감으로 옮기고, 결정 카드와 시간표 사이에 Guru 한 줄(안으로 파인 띠). 고른 항목에 따라 관점이 바뀐다(매출 → Voss 실행 조건, 콘텐츠 → Ogilvy 리서치 우선, 그 밖 → 이번 시간대 관점). 문구는 `packages/guru-guidance` 카드의 재구성 요약이라 "자료 요약"으로 표시하고 따옴표 인용으로 쓰지 않는다 |
| 7c | 집중 스택 (새 안) | 가운데 칼럼에 번호 붙은 네 단계(지금 할 것 · 오늘 할 일 · 다음 일정 · 승인 대기)만, 나머지는 더보기 드로어. 390px로 그대로 접힌다 |

## 현황 — 3안
6e는 차트가 화면 절반이지만 다음 행동이 없었고, 6f는 칩 색(초록·하늘·빨강)으로 단계를 칠했다. 세 안 모두 숫자 옆에 상태나 다음 행동을 붙이고, 계열은 Moonstone 명도 + 빗금으로 구분한다.

| 안 | 이름 | 요지 |
| --- | --- | --- |
| 7d | 판단 대시보드 (6e에서) | KPI에 지난 같은 기간 대비, 가리키면 그날 값을 읽어 주는 차트(←/→), OKR 요약 + 최근 활동. 집계 ↔ OKR·KPI 토글 |
| 7e | 운영 지도 (지금 분포 패널에서) | 프로젝트·콘텐츠·매출·자동화 2×2 타일 — 큰 숫자 하나, 상태 한 줄, 행동 하나. 타일 → 드로어 |
| 7f | 기록 밀도 · 주간 해석 (6f에서) | 사실(원장 계산) · 해석(◇ 권장, 근거 필수) · 판단(○ 미정 → ● 확정) 세 줄 + 명도 히트맵 + 지난 기간 비교 + 프로젝트 상태 |

## 6c~6f에서 DESIGN.md에 맞춘 것
- 지금 선은 빨강이 아니라 Moonstone(§5.2: 오늘·진행 중은 빨강 아님). 빨강은 긴급 KA·막힘·자동화 실패에만, 1px 레일이나 글리프로.
- 진행·완료·실행 전 칩의 하늘색·초록을 글리프 + 글(○ 대기 · ◐ 진행 · ⏸ 승인 대기 · ✓ 완료 · 팔각 막힘)로.
- 히트맵의 실패 칸은 빨강 면 대신 팔각 글리프 + 건수(빨강 예산).
- 프레임 배경의 색 있는 radial gradient를 중립 선형으로(§4).
- 금액은 만·억 표기(§8.1, 2026-10-06 확정).
