## 지킨 규칙
- 빨강은 500자를 넘는 연결 글(올라가지 않는 실패)에만 — 1px 레일 + 글자, 17b는 링과 글자.
- 금지어 · AI 후보는 권장(점선 · ◇ 마름모 + 직접 라벨), 막지 않는다.
- 현재 위치(쓰는 블록 번호 · 고른 형식 · 현재 메뉴)는 잉크, 주 행동은 `올리기` 하나.
- 숫자 · 문장 · 브랜드 상태는 모두 **예시 값**이다(코드에 넣지 않는다).

## 운영자가 고를 것
1. 세 안 중 하나, 또는 조합(예: 17a의 위 한 줄 · 떠 있는 바 + 17c의 메모 칸, 17b의 카드 편집기 + 17a의 숨김 규칙).
2. **여백 칸을 다시 걷을지.** 17a는 16a에서 막 들인 양옆 여백 칸을 빼고 목차는 막대, 말투는 글 안 표시로 옮긴다. 16a 스펙 §3의 표면 예산을 다시 고친다.
3. **AI를 어디에 둘지.** 지금은 원고지 안에 요청/템플릿 · 버튼 3개 · 다른 작업이 늘 있다. 17a 뜨는 판 / 17b 제안 카드 / 17c 가운데 단추 중 하나로 줄인다(요청 · 템플릿 · 다른 작업은 세 안 모두 한 단계 안으로).
4. **17b를 고르면** 지금 올리기를 오른쪽 판에서 바로 할지(창 없이), 지금처럼 창을 거칠지.
5. **휴대폰.** 17a는 그대로 한 단, 17b는 카드만 남기고 재료 · 올리기는 시트로, 17c는 `메모 | 원고` 탭으로 그리는 것을 권장한다(이번 목업에는 휴대폰 화면을 그리지 않았다).
