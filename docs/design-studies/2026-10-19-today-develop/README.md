## 왜 다시 만들었나
7a를 실제로 띄워 보니 보드 아래에 주간 리포트 · 30초 실행 오더 · 문의 알림 · 지금 급한 것 · 보조 정보가 다섯 겹으로 쌓여 스크롤이 길었다(표면 예산, CLAUDE.md). 세 안은 그 문제를 각기 다른 축으로 푼다.

| 안 | 이름 | 축 | 요지 |
| --- | --- | --- | --- |
| 9a | 하루 시계 | 시간 | 같은 화면이 아침(오늘 3개 고르기 + 사실 요약) · 낮(지금 일정 + 오늘 3개 + 연락·승인) · 저녁(1분 리뷰 — 에너지 달 위상, 3개 끝냄/내일로, 한 줄 회고, 내일 첫 일)으로 바뀐다. 위쪽 하루 띠가 위치를 말한다. 시간대는 기기 시계가 정하고(자동 테마와 같은 07·18시 경계) 다른 시간대는 잠깐 열어 볼 수 있다 |
| 9b | 보드 + 들어온 것 레일 | 한 화면 | 7a 보드는 두고, 보드 아래 다섯 겹을 오른쪽 "들어온 것" 레일 하나로 모은다. 항목 하나에 행동 하나(다시 시도 · 승인/보류 · 열기 · 드로어 · 누를 때만 받는 30초 오더), 처리하면 사라진다. 필터 전체 · 즉시 · 승인. 일정은 가로 다섯 칸 |
| 9c | 오늘 3개 | 커밋 | 주인공을 목록이 아니라 세 자리로. 할 일 · 연락 · 일정 준비 · 들어온 것에서 셋만 올리고 자리마다 15분 집중 → 끝. 자리가 차면 "자리 없음 · 하나 빼기" |

## 지킨 규칙
- 빨강은 긴급 KA · 자동화 실패에만, 1px 레일과 글자로(§5.2·§5.3). 진행 중은 시계 글리프 + 중립 글자.
- 저장을 말하는 문구는 서버 확인 뒤에만("저장이 확인되면 한 번 축하", §8.1 저장 봉투). 30초 오더 · AI 초안은 누를 때만(agent-layer-direction — 어느 계층도 자동으로 일을 만들지 않는다).
- 깊이감 값은 5a·8a(허브 `--nm-*`)와 같은 어휘. 에너지 아이콘은 기존 `EnergyMoon` 달 위상, 연속은 단색 불꽃(`StreakMark`).

## 목업 안의 숫자
모든 수치·이름은 형태를 보여 주는 **예시 값**이고 각 아트보드에 `예시 값 · 목업`으로 표시했다. 앱 코드로 옮길 때는 원장에서 읽는다(CLAUDE.md 목업 데이터 금지).

## 운영자가 고를 것
- 9a · 9b · 9c 중 방향 하나, 또는 조합(예: 9b 레일 + 9a 저녁 리뷰, 9c 세 자리를 9a 아침에서 고르기).
- 9a를 고르면: 시간대 경계(07·11·18시)와 다른 시간대 미리보기 허용 여부.
- 9c를 고르면: 15분 타이머를 캘린더 블록으로 남길지(지금 "15분 집중" 버튼은 캘린더로 보낸다).
