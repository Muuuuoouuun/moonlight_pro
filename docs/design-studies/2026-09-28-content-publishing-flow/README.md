## 핵심 원칙

- 프롬프트 3층: ① 형식 기본 요청문 → ② 브랜드 말투 → ③ 이번 글 요청. 사실·수치는 원문 메모에서만.
- 모든 형식이 같은 틀: 본문 → AI 줄(형식별 3개) → 하단 고정 바(주 행동 · 예약 · 발행했음).
- 상태는 색이 아니라 모양·말(DESIGN.md §5.3): 예약=파선, 지금=강조, 발행=체크, 놓침=빨강(실패만), 확인 필요=점선, 권장=◇.

## 확정 결정 (운영자, 2026-09-29)

1. 원고 화면 하단 바에 `예약` 추가(표면 예산 +1) — 본문 카드 컨트롤 ≤ 6, AI 직접 버튼 ≤ 3(형식별).
2. 형식 탭(스레드·카드뉴스·유튜브·카피)을 화면 위에 둠. 채널 추가는 더보기에 유지.
3. **놓침** = 그날 밤 정리 때 안 올린 예약. 낮에는 "시각 지남"(중립). 밤 정리 시각은 상수 하나(기본 22:00 — 운영자 미지정, 조정 가능).
4. **성과 입력 알림** = 매주 한 번(월요일, 요일은 운영자 미지정 기본값). 지난주 발행 글의 조회·공유·답글을 한 번에 입력.
5. **구현 범위** = 1단계(예약·알림·로그) + 2단계(형식별 프롬프트·전용 AI 버튼)를 함께. 통합 틀 → 잘 된 글 재구성 → 카피·종합은 그 뒤.
6. **브랜드 미지정**이면 AI 말투를 '담백하게'로 자동 전환하고 헤더에 `브랜드 미지정` 표시.

## 구현 현황 (2026-09-29)

| 구분 | 상태 | 비고 |
|---|---|---|
| 형식 탭(스레드·카드뉴스·유튜브) | 구현 | 원고 화면 위, 없으면 빈 결과물 생성 |
| 형식별 기본 요청문(스레드·카드뉴스·쇼츠) | 구현 | 서버 상수 `packages/content-manager/format-prompts.ts`, 후보 스냅샷에 기록 |

| 예약 저장·해제·다시 예약 | 구현 | `content_schedules`(마이그레이션 `20260929_0055`), 예약 창, 낙관적 잠금 |
| 홈 '지금 올릴 글' | 구현 | 지금 / 시각 지남 / 놓침, 30분 뒤 미루기. 놓침 4건 이상이면 개수로 접음 |
| 놓침 밤 정리 크론 | 구현 | 매일 22:00 KST(`/api/cron/schedule-sweep`, vercel.json 13:00 UTC), 발행 여부 교차 확인 후 판정 |
| 전용 AI 버튼 | 부분 | 스레드 `첫 줄 3안`만. 표지 문구 5안·훅 5안·썸네일 등은 새 AI 작업이라 다음 |
| 5분 푸시 알림 | 미구현 | 지금은 홈 카드와 원고 화면 표시. 푸시는 배포 크론 주기·채널이 정해져야 함 |
| 발행 로그 화면 | 구현 | `dashboard/content/publish`(콘텐츠 탭 `발행`). 이번 주 7칸 + 시간 순 목록(예약됨·올릴 차례·놓침·발행됨·예약 해제) + 글별 이력. 예약과 발행 기록을 결과물 단위로 합치고 발행 기록이 있으면 발행됨. 성과 수치는 읽기 전용이며 입력·수정은 성과 화면이 소유. 월 캘린더·기간 이동은 다음 |
| 성과 주간 입력 알림 | 미구현 | 매주 월요일(기본값, 미지정) |
| 카피라이트·종합 패키지·잘 된 글 | 미구현 | 통합 틀 이후 |

**운영 적용:** 서울 운영 DB에 `20260929_0055`를 적용했고 `db:check`가 통과했다(2026-09-29). Hub·Engine은 `09.bigmac2.0`에서 배포했다([배포 기록](../../guides/vercel-deploy.md#2026-09-2930-운영-적용-기록)). 예약 저장·발행 로그의 인증된 화면 왕복과 밤 정리 크론의 실제 실행은 아직 검증하지 않았다. 밤 정리 크론에는 배포 환경 변수 `CRON_SECRET`이 필요하다.

**운영자 미지정 기본값:** 밤 정리 시각 22:00 KST(`SWEEP_HOUR_KST`), 빠른 시각 선택 3개(1시간 뒤 · 저녁 7시 · 아침 8시 — 발행 로그가 쌓이면 실제 시간대로 교체).

## 추천 구현 순서

① 예약·알림·로그(2~5) → ② 형식별 프롬프트·전용 AI 버튼(8~10·14) → ③ 통합 원고 틀(13) → ④ 잘 된 글 재구성·후속편(6) → ⑤ 카피·종합(11·12).
