## 구조

소재 → 원고 → **예약** → **발행** → 성과, 다섯 단계. 단계마다 세 층으로 나눈다.

| 층 | 소재 | 원고 | 예약 | 발행 | 성과 |
|---|---|---|---|---|---|
| 내가 | 한 줄 적기 | AI 초안·다듬기 | 시각 한 번 누르기 | 알림 → 복사 → 붙여넣기 → URL | 다음 날 숫자 3개 |
| 허브 | 소재함 | 자동 저장·버전·템플릿 | 예약 목록·주간 캘린더 | 홈 "지금 올릴 글"·놓친 예약 | 성과 탭·잘 된 글 |
| 자동 | 초안 제안(Flywheel, 배포 설정 필요) | — | 5분마다 예약 확인 → 알림 | (나중) 승인한 글만 Threads API | (나중) 수치 수집 |

상태: `아이디어 → 초안 → 예약됨 → 올릴 시각 → 발행됨 → 성과 기록`, 예외 `놓침`(예약 +2시간, 권장). 모든 전환은 누가·언제·수동/자동으로 로그에 남는다.

## 핵심 원칙

- 프롬프트 3층: ① 형식 기본 요청문 → ② 브랜드 말투 → ③ 이번 글 요청. 사실·수치는 원문 메모에서만.
- 모든 형식이 같은 틀: 본문 → AI 줄(형식별 3개) → 하단 고정 바(주 행동 · 예약 · 발행했음).
- 상태는 색이 아니라 모양·말(DESIGN.md §5.3): 예약=파선, 지금=강조, 발행=체크, 놓침=빨강(실패만), 확인 필요=점선, 권장=◇.
