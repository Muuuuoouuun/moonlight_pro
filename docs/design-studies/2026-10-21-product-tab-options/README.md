## 지킨 규칙
- 모드는 색이 아니라 질감으로: 운영중 = 채운 타일 · 실선, 제작중 = 빗금 타일 · 점선, 중지 = 빈 실선, 기획 = 점 테두리(§14.3). 글리프 ● ◐ ⏸ ○ + 글자를 같이 둔다.
- 빨강은 main CI 실패(1px 레일 + 글자)와 12c의 거절 배너뿐. 집중 칸이 가득 차도 빨강을 쓰지 않는다(§14.4). 사이드바 `제품` 배지 숫자는 고장이 있을 때만 빨강.
- 게이트는 막지 않고 알려 준다: 점선 ◇ + "출시로 올리려면 …"(§4.1). 권장은 점선 마름모 + `권장` 직접 라벨(§5.3).
- 추세선은 한 색 명도, 선 아래 10% 면, 이번 달 끝점만 1.4초 링(§14.5). 매출이 없으면 점선 바닥선만, 펄스 없음. 감소 모션에서는 링이 꺼진다. 그래프마다 월별 값을 읽는 접근 가능한 이름이 있다.
- 금액은 만·억 단위. 제품 이름은 자리표시(`제품 A`~`F`), 숫자는 모두 **예시 값**이다(코드에 넣지 않는다).
