## depth B에서 더한 것
- **같은 면이 솟는다**: 바탕과 같은 면(`--face`)에 위-왼쪽 빛 · 아래-오른쪽 그림자 두 겹. 사이드바·패널·지표 타일·보조 버튼·할 일 행이 솟는다.
- **누르는 곳은 홈**: 빠른 캡처 입력, 세그먼트 트랙, 진행 게이지 트랙, 주간 칸, 시간표, 하루 리뷰 요일은 눌린 홈이다. 버튼은 누르는 순간 홈으로 바뀐다.
- **현재 위치는 잉크**: 사이드바 현재 항목·세그먼트 선택·primary·완료 체크는 잉크 pill(라이트 먹색 · 다크 은색)로 반전한다.
- **이번 주만 솟는다**: 현황의 KR 주간 칸은 지난 주 = 홈, 이번 주 = 솟은 면 + Moonstone 1px, 앞으로 올 주 = 점선.

## 지킨 규칙
- 빨강은 놓친 약속·막힘·KPI 선 밖에만, 1px 레일 + 글자로(§5.2 · §5.3). 완료는 체크 글리프 + 명도 하강, 초록 없음.
- 확실성: 제안 팁은 점선 마름모 + 직접 라벨, 일부 데이터는 점선 배지(§5.3).
- 금액은 만·억 단위. 고객 이름은 자리표시(`고객 A`), 숫자는 모두 **예시 값**.

## 미끄러짐 (사이드바 · 세그먼트 잉크 pill)
거리 비례 시간 280ms + 0.75ms/px(최대 520ms), 곡선 `cubic-bezier(0.16, 1, 0.3, 1.04)` — 깊은 감속 + 끝에서 이동 거리의 약 1%만 넘쳤다 놓임, 늘어남 없음(2026-10-21 운영자 선택: "부드럽게" + "감속 살짝 더, 튕김 매우 살짝" + "조금 더 느리게"). 현재 항목 글자색은 이동 시간의 35% 지점부터 반전해 pill이 도착할 때 맞춰진다. 감소 모션에서는 이동 없이 바로 놓인다. 허브에 옮기면 시간·곡선은 §9 토큰으로 새로 등록해야 한다(`--dur-slide` 계열).
