공통(A·B·C): 푸터에 `⌘↵ 저장` 힌트 + `취소`(고스트) + 잉크 pill `변경사항 저장`, 닫기는 솟은 원형 버튼. 한글 라벨에서 대문자 변환·넓은 자간을 뺀다.

## 지킨 규칙
- 글꼴은 SUIT Variable 하나, 단축키만 JetBrains Mono(§6). 데이터 값 ≥12px, 보조 ≥10.5px(§8.1).
- 입력칸은 depth C 눌린 홈 + 3:1 경계(`--line-control`), 포커스는 `--moon-300` 1px(§11). 휴대폰 16px 입력은 공용 규칙이 그대로 맡는다.
- 색 의미 없음 — 상태·우선순위도 중립 글자, 선택만 잉크(§5.2).

## 운영자가 고를 것
1. 안: A(공용·변경 적음) · B(이 팝업만 속성 시트) · C(타일, 가장 짧음).
2. A를 고르면 다른 편집 팝업(컨테이너·거래·리드 등)도 같은 글꼴 위계로 바뀐다 — 함께 바꿀지.
3. C를 고르면 칸 모서리 10px가 글쓰기 칸 6px 규칙(§7, §15 2026-09-21)의 예외가 된다.
4. 저장 버튼을 pill로 할지(시안) 지금처럼 각진 6px로 둘지.
