## 두 안
| | A 회의실 한 장 (권장) | B 현행 3면 유지 |

## 지킨 규칙
- 칩은 눌린 홈 위 고른 칸만 잉크(depth C 세그먼트 문법). 링크 칩은 점선 + `↗`, 모델 호출 0.
- 빨강 없음(실패 `기록 못 함` 한 곳만 예정). 권장은 점선 `◇ 권장`, 영수증 `업무 변경 없음`은 실선, 근거 불확실은 `근거 확인 안 됨` 점선.
- 제목 20px/500 그대로(Futura 확장 아님). 레일 232/220, 가운데 결론 먼저 — V4 유지.
- 아바타는 모노그램 타일(P5). 숫자·브랜드 이름·답변 본문은 **예시**다.
