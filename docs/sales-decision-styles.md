# 세일즈 의사결정 스타일 완전 분류

---

## 왜 이걸 알아야 하는가

같은 말을 해도 어떤 사람에겐 설득이 되고, 어떤 사람에겐 반감이 된다. 이유는 단순하다 — 결정하는 방식이 사람마다 다르기 때문이다.

세일즈에서 의사결정 스타일을 파악하면:
- 같은 정보를 다른 순서와 언어로 전달할 수 있고
- 어떤 저항이 왜 생기는지 예측할 수 있으며
- 다음 행동이 어디서 막히는지 진단할 수 있다

---

## 핵심 5가지 의사결정 스타일

### 1. 논리형 (Analytical / 데이터 주도)

| 항목 | 내용 |
|------|------|
| 핵심 욕구 | 정확성, 확신, 실수 없음 |
| 두려움 | 잘못된 결정 → 비판받는 것 |
| 결정 속도 | 느림 (정보 수집 충분히 후) |
| 신뢰 기반 | 데이터, 수치, 검증된 사례 |
| 대화 특징 | 질문이 많음, 세부 사항 파고듦, 조용함 |

**세일즈 접근법**
- ROI 수치, 비교표, 케이스 스터디 제공
- "왜 이 수치가 나왔는지" 근거까지 설명
- 충분한 검토 시간 허용 (재촉 금물)
- 자료를 문서로 남겨줌 (말보다 글)

**실수 패턴**: 감성적 접근, 압박 클로징 → 즉시 신뢰 붕괴

---

### 2. 관계형 (Relational / 사람 주도)

| 항목 | 내용 |
|------|------|
| 핵심 욕구 | 신뢰, 안심, 좋은 관계 유지 |
| 두려움 | 갈등, 불화, 관계 손상 |
| 결정 속도 | 중간 (주변 의견 확인 후) |
| 신뢰 기반 | 담당자에 대한 인간적 신뢰 |
| 대화 특징 | 개인적 이야기 많음, 공감 반응 |

**세일즈 접근법**
- 비즈니스 전에 라포 형성을 충분히
- "다른 분들도 처음엔 비슷한 고민을..." → 공감 → 사례
- 팀/동료가 어떻게 반응할지 함께 고민해줌
- 계약 후에도 꾸준한 연락 유지

**실수 패턴**: 첫 만남에 바로 제안 → "이 사람은 나한테 관심 없고 팔기만 하려는구나"

---

### 3. 권위형 (Dominant / 결과·통제 주도)

| 항목 | 내용 |
|------|------|
| 핵심 욕구 | 통제권, 빠른 결과, 지위 확인 |
| 두려움 | 시간 낭비, 약해 보임, 통제 상실 |
| 결정 속도 | 빠름 (조건만 맞으면 즉결) |
| 신뢰 기반 | 실력·성과 증명 |
| 대화 특징 | 직접적, 결론부터, 질문 짧음 |

**세일즈 접근법**
- 핵심 결론 먼저 → 근거 나중
- "이 솔루션으로 X만큼의 결과가 납니다" (짧고 강하게)
- 선택지 2개 제공 → 본인이 결정하게 유도
- 미팅 시간 철저히 준수, 쓸데없는 말 없애기

**실수 패턴**: 장황한 설명, 허락 구하는 태도 → "이 사람 신뢰 못 하겠다"

---

### 4. 직관형 (Visionary / 비전·아이디어 주도)

| 항목 | 내용 |
|------|------|
| 핵심 욕구 | 새로움, 가능성, 영향력·의미 |
| 두려움 | 지루함, 현상 유지, 뒤처짐 |
| 결정 속도 | 빠르게 흥분 → 실행은 느림 |
| 신뢰 기반 | 비전의 크기와 흥미로움 |
| 대화 특징 | 아이디어 많이 던짐, 주제 자주 바뀜 |

**세일즈 접근법**
- Big Picture 먼저 → "이걸 하면 업계 판도가 바뀝니다"
- 스토리텔링, 사례의 드라마틱한 면 강조
- 그들의 아이디어를 제안에 흡수 ("말씀하신 것처럼...")
- 세부 실행은 다른 담당자와 따로 처리

**실수 패턴**: 스펙 시트만 들이밀기, 세부 조항부터 시작 → 집중력 즉시 이탈

---

### 5. 안정형 (Steady / 안전·합의 주도)

| 항목 | 내용 |
|------|------|
| 핵심 욕구 | 안전, 예측 가능성, 조직 화합 |
| 두려움 | 변화, 리스크, 혼자 결정하는 것 |
| 결정 속도 | 매우 느림 (합의 구조 필요) |
| 신뢰 기반 | 안정성 증명, 장기 레퍼런스 |
| 대화 특징 | 신중, 말 아낌, 내부 절차 강조 |

**세일즈 접근법**
- "많은 분들이 이미 사용 중" → 사회적 증거 강조
- 리스크 제거 장치 제공 (무료 파일럿, 단계적 도입)
- 내부 보고용 자료 대신 만들어주기
- 체크리스트·로드맵으로 예측 가능성 제공

**실수 패턴**: "지금 결정 안 하시면 혜택 없어요" → 즉시 방어 모드 진입

---

## 한국 시장 특수 스타일 2가지

### 6. 체면형 (Face-saving / 지위·의전 주도)

권위형과 비슷하지만 타인의 시선과 품격에 더 민감하다.

| 항목 | 내용 |
|------|------|
| 핵심 욕구 | 지위에 맞는 품격, 내외부 시선 관리 |
| 두려움 | 격에 맞지 않는 선택으로 체면 손상 |
| 결정 속도 | 중간 |
| 신뢰 기반 | 브랜드 위상, 프리미엄 포지셔닝 |
| 대화 특징 | 명함·직함 강조, 의전 민감 |

**세일즈 접근법**
- "귀사 수준에 맞는 솔루션"으로 포지셔닝
- 레퍼런스는 동급 이상 기업으로 제시
- 미팅 의전·자리 배치·호칭 사소한 것까지 챙기기
- 저가 옵션 먼저 꺼내는 것 절대 금물

**실수 패턴**: 저가 포지셔닝, 의전 실수 → 관계 자체가 흔들림

---

### 7. 집단합의형 (Consensus / 조직 승인 주도)

| 항목 | 내용 |
|------|------|
| 핵심 욕구 | 조직 내 갈등 없는 통과, 책임 분산 |
| 두려움 | 혼자 결정했다가 나중에 비판받는 것 |
| 결정 속도 | 매우 느림 |
| 신뢰 기반 | 이해관계자 전원 설득 가능성 |
| 대화 특징 | "내부 검토 후", "위에 보고해봐야" 자주 언급 |

**세일즈 접근법**
- 담당자를 내부 세일즈맨으로 만들기
- 보고 자료를 직접 제공 (담당자가 윗선 설득하도록)
- 각 이해관계자별 설득 포인트 별도 정리
- 결재 라인을 파악하고 각 단계 지원

**실수 패턴**: 담당자만 설득하고 끝 → 내부에서 조용히 탈락

## 스타일별 비교 요약

| 스타일 | 결정 기준 | 결정 속도 | 핵심 언어 | 피해야 할 것 |
|--------|-----------|-----------|-----------|-------------|
| 논리형 | 데이터·증거 | 느림 | "수치로 보면" | 감성 호소, 재촉 |
| 관계형 | 신뢰·공감 | 중간 | "함께" "믿고" | 비즈니스만 얘기 |
| 권위형 | 결과·통제 | 빠름 | "성과" "최단" | 장황함, 굽실거림 |
| 직관형 | 비전·가능성 | 불규칙 | "판도" "혁신" | 스펙 중심 설명 |
| 안정형 | 안전·합의 | 매우 느림 | "검증된" "단계적" | 긴박감 조성 |
| 체면형 | 위상·시선 | 중간 | "격에 맞는" | 저가 포지셔닝 |
| 집단합의형 | 조직 승인 | 매우 느림 | "내부 공유용" | 담당자만 설득 |

---

## 실전: 스타일 진단법

미팅 초반 3분 안에 파악하는 신호들:

| 행동 신호 | 추정 스타일 |
|-----------|-------------|
| 질문 많음 + 메모함 | 논리형 |
| 개인 얘기 먼저 꺼냄 | 관계형 |
| "결론이 뭔가요?" 바로 물음 | 권위형 |
| 아이디어 연속 제시 | 직관형 |
| "내부 검토 후..." 자주 언급 | 안정형 / 집단합의형 |
| 명함·직함 강조 | 체면형 |

---

## 핵심 원칙

사람을 바꾸려 하지 말고, 내 메시지를 그 사람의 언어로 번역하라.

같은 제품을:
- 논리형에겐 → ROI 시트로
- 관계형에겐 → 신뢰 스토리로
- 권위형에겐 → 한 줄 결론으로
- 직관형에겐 → 미래 그림으로
- 안정형에겐 → 레퍼런스 리스트로
- 체면형에겐 → 프리미엄 포지셔닝으로
- 집단합의형에겐 → 내부 설득 패키지로

팔아야 한다.
