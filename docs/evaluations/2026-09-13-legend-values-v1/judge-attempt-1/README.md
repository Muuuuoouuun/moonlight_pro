# 제외한 첫 판정 시도

생성 답변은 변경하지 않았다. 이 시도의 부분 판정은 최종 집계에서 제외한다.

- 내용 판정에서 출처가 없다는 이유로 감점한 사례가 있어 사전 기준을 위반했다.
- provenance의 fidelity JSON 예시에 객체 구조가 빠져 모델이 숫자를 반환했고 엄격한 검증에 실패했다.
- 최종 판정은 내용 단계에서 불필요한 출처 요약을 제거하고, 출처 부재 감점 금지·업무 사실 우선 검증을 명료화하며 JSON 스키마를 제공한 뒤 전체 60개 응답을 다시 평가한다.
- 아래 원 판정과 실패 응답·토큰·메타데이터를 보존한다. 선택적 재채점이나 응답 재생성은 하지 않는다.
