# Legend 가치관 카드 v1 — 원문 대조와 개발 판단

> 상태: 실제 답변 60개를 사용한 개발 세트 파일럿. 개선 권장안이며 활성화 승인이나 인물의 능력 평가가 아니다.
> 기준: 문서 커밋 `8605338`, [고정 입력과 지침](manifest.json), [생성 답변](responses.jsonl), [자동 판정](assessments.jsonl), [집계](summary.json).
> 측정일: 2026-09-13 KST. 원 기록의 타임스탬프는 UTC다.

현재 긴 가치관 카드를 그대로 넣는 방식은 기본 적용 전에 수정하는 것을 권장한다. 이번 입력에서 C의 자동 평균은 A보다 3.11점 낮았고, 700자를 넘긴 답변은 A 9/20개에서 C 14/20개로 늘었다. 더 중요한 문제는 **자동 평가자가 60개 모두 사실성 4/4를 주면서, 입력에 없는 상태·숫자·단정을 놓쳤다는 점**이다. C의 ‘자동 기준 통과 5/20’도 검증된 품질 통과율로 사용할 수 없다.

## 1. 무엇을 측정했는가

9인(소크라테스, 아인슈타인, 링컨, 시어도어 루스벨트, 프랭클린 루스벨트, 잡스, 베이조스, 버핏, 쉬나드)의 초기·후속 답변과 Council 두 조합을 비교했다. A는 공통 지침과 가상 업무 기록, B는 A에 검토된 원전 요약을 추가한 조건, C는 B에 인물별 가치관 지침을 추가한 조건이다. 생성 모델은 `gemini-3-flash-preview`, 자동 평가 모델은 `gemini-3.1-pro-preview`다.

이는 Legend 관점을 Mentor와 Council에 적용하기 위한 **프롬프트 비교**다. 현행 Guru 라우팅, 기록 검색, 실행 페르소나 5개, 기존 세일즈·마케팅 15인이나 실제 앱의 장기 사용 효과를 측정한 것은 아니다. 앞선 문서 리뷰의 8/10·9/10은 문서 품질 의견이며 아래 성능 측정과 다른 척도다.

| 조건 | 자동 평균 /100 | 자동 기준 통과 | 700자 초과 | 평균 글자 수 |
|---|---:|---:|---:|---:|
| A: 공통 지침 + 기록 | 88.55 | 11/20 | 9/20 | 684.35 |
| B: A + 출처 요약 | 87.44 | 9/20 | 11/20 | 746.05 |
| C: B + 가치관 지침 | 85.44 | 5/20 | 14/20 | 779.90 |

B−A는 −1.11점, C−B는 −2.00점이다. 평균은 자동 판정의 가중 합이며 평가자의 오류를 포함한다. 문서가 길어지고 출력 구조를 더 요구하는 효과까지 함께 비교한 것이므로 차이를 ‘인물 이름의 효과’나 ‘가치관 자체의 해로움’으로 해석하지 않는다. 시나리오마다 질문이 달라 인물 간 순위도 만들지 않는다.

## 2. 자동 평가가 놓친 문제

[별도 Codex 검토의 전체 대조 기록](answer-audit.json)은 A/B/C 모두를 원 입력과 비교한다. 이 검토는 자동 점수를 참고하지 않는 별도 AI 검토이며, 인물·조건을 공개한 상태다. 앞선 검토의 일부 오류 후보를 알고 시작했으므로 완전 독립 검증은 아니다. 사람의 검증이나 확정된 정답 집합으로 표현하지 않는다. `hard`는 입력 사실의 명확한 변조·없는 상태의 확정·명시 제약 위반, `concern`은 근거가 약한 해석·귀속·판단 기준을 구별하기 위한 표지다. 이 기록으로 자동 점수를 사후 덮어쓰지 않는다.

| 조건 | 별도 검토의 hard 답변 | hard 지적 건수 | concern 답변 |
|---|---:|---:|---:|
| A | 4/20 | 5 | 14/20 |
| B | 2/20 | 2 | 12/20 |
| C | 2/20 | 2 | 11/20 |

별도 검토는 8개 답변에 hard 9건, 그와 별개로 concern 46건을 남겼다. 두 분류는 한 답변에 함께 있을 수 있다. hard 답변 중 소크라테스 첫 답변 A/B/C 세 개는 자동 기준을 통과했다. 이 표는 특정 검토 기준으로 발견한 문제 수이며 누락이 없다는 보장이나 조건별 오류율의 통계적 추정이 아니다.

## 4. 다음 개발 순서와 확인 기준

1. **공통 사실·상태 계약부터 강화한다.** 입력의 직접 사실, 가설, 새 제안을 구별한다. 대체 문장·이메일 초안도 같은 검사를 받는다. 고객 발언을 강화하거나 미측정 상태를 ‘측정 중’으로 바꾸지 않는 반례를 추가한다.
2. **가치관 카드를 집필용과 실행용으로 나눈다.** 실행 지침에는 우선 가치, 감수할 비용, 판단을 바꿀 조건만 짧게 넣는다. 고정된 첫 문장을 반복할 필요는 없다. 각 인물의 실제 선택 차이가 없으면 공통 답변과 같아도 된다.
3. **시간·권한·휴식 제약을 행동 선택에 먼저 적용한다.** 0분이면 새 작업을 배정하지 않고 재검토 조건만 남길 수 있어야 한다. 숫자 임계치는 관찰값인지 제안값인지 명시하고, 근거 없는 고정 수치 대신 확인 가능한 사건을 사용한다.
4. **평가자를 별도로 검증한다.** 이번 교정 예제는 출처 없는 정확한 답변과 명백한 조작은 구별했지만 실제 답변의 미묘한 오류를 놓쳤다. 진행 상태 변경, 고객 발언 확대, 확률·인과 과장, 제약 무시를 포함한 알려진 반례와 정상 답변으로 오탐·미탐을 확인한다. 그 전에는 자동 점수로 적용 여부를 결정하지 않는다.
5. **개선한 v2는 새 실행으로 비교한다.** 이번 60개와 결과는 그대로 보존한다. 미공개 사례, 후속 턴, 반복 생성에서 공통 지침만 있는 조건과 다시 비교하고 분량 준수·명확한 사실 오류·제약 위반을 먼저 본다. 그 뒤 실제 사용자의 행동 채택·실행 부담·도움 여부를 확인한다.

v2의 권장 확인 기준은 ‘알려진 사실 변조와 제약 위반을 평가자가 검출’, ‘동일 분량 안에서 가치가 선택과 비용에 반영’, ‘새 사실에 맞춰 조언 수정’이다. 인물 이름 언급이나 예시 첫 문장의 재현 자체에는 가점을 주지 않는다. 표본 수·반복 횟수와 실제 사용 기준은 다음 실행 전에 고정한다.

## 5. 재현과 검증

원 응답은 한 번 생성한 60개를 유지했다. 첫 자동 판정은 출처 부재 감점 등 사전 기준 위반과 출력 형식 오류가 있어 [부분 결과와 제외 사유](judge-attempt-1/README.md)를 보존한 뒤 교정했다. 교정 후 내용 평가 20회와 사실·귀속 평가 20회를 다시 실행했다. 점수가 좋아질 때까지 답변을 재생성하거나 선택하지 않았다.

평가 코드의 회귀 테스트 10개와 기존 persona registry 검사를 통과했다. 생성·판정 요청 100개의 해시, 카드·입력의 고정 해시, 60개 답변의 글자 수·후속 대화 보존, 점수·통과 개수를 별도로 재계산했다. 별도 대조의 60개 ID, 지적 55건의 원문 인용과 입력 근거, 원 파일 해시 2개도 일치했다. 이는 측정 자료의 무결성 검사이며 모델 답변이 모두 정확하다는 뜻은 아니다.

현재 결과를 API 호출 없이 다시 집계할 때:

```bash
node scripts/evaluate-legend-personas.mjs report --out docs/evaluations/2026-09-13-legend-values-v1
node --test scripts/evaluate-legend-personas.test.mjs
```

새 실행의 준비·생성·판정 명령은 [측정 계획](../../superpowers/plans/2026-09-13-legend-persona-measurement.md)에 있다. 새 버전은 별도 출력 디렉터리를 사용한다. 모델 API의 변동과 확률적 생성 때문에 같은 입력이 같은 답변을 보장하지 않는다. `report`는 원 기록을 재집계하며 보고서 작성 시각과 실행 이력만 갱신한다.
