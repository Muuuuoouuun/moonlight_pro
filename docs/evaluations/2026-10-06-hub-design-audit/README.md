## 0. 한눈 요약

Hub는 규칙(DESIGN.md)과 가드 테스트가 촘촘하지만, **화면 단위로 보면 세 가지가 반복된다.**

1. **작고 흐린 글자가 기본값이 됐다.** 렌더된 데스크톱 텍스트의 41%가 12px 미만이고, 기본 본문이라는 14px은 거의 쓰이지 않는다. 다크 테마의 `--fg-faint`(404곳)는 대비 2.4~3.0:1로 큰 글자 기준도 못 넘는다. 저녁 18시 이후 자동 다크에서 라벨·안내문·빈 상태 설명이 읽히지 않는다.
2. **같은 것을 여러 번, 여러 이름으로 말한다.** 화면 제목이 탑바·탭·eyebrow·h2로 3~4번 반복되고, `Preview · 연결 필요` 배지가 한 화면에 3~5개, 같은 대상의 이름이 화면마다 다르다(할 일/작업/하위 아이템/카드, 딜/거래, 컨텐츠/콘텐츠/Content Log). 금액 표기 6종, 영문·한글 라벨 혼용이 전 앵커에 있다.
3. **주 행동이 경쟁하거나 끊긴다.** 탑바 `New`가 모든 화면에서 primary라 페이지 주 버튼과 늘 경쟁하고, 생성 대상이 없는 화면에서는 검색 팔레트를 연다. 오늘(daily-brief)은 섹션 11~16개, 프로젝트는 보기 7개 + 탭 5개, AI 입구는 30곳이다. 반대로 매일 하는 행동(전화 걸기, 문의를 고객으로 등록, 실패한 자동화 고치기)은 화면에서 바로 이어지지 않는다.

### 2.1 대비 (WCAG, oklch 토큰 → sRGB 계산)

### 2.2 글자 크기와 스케일

- 렌더 실측: 데스크톱 25화면 텍스트 1,657개 중 10.5~11.5px이 629개, 12~13.5px이 889개, **14px은 5개**. 실질 본문은 13px, 라벨은 10.5~11.5px이다(Preview 상태라 라벨 비중이 실데이터보다 높게 잡혔을 수 있다).
- 코드 전수: 인라인 `fontSize` 1,112개 중 12px 미만 503개. 상위 파일 `revenue.jsx` 85 · `daily-brief.jsx` 45 · `automations.jsx` 37 · `evolution-settings.jsx` 30 · `my-work.jsx` 26.
- **하한(10.5px) 미달 9곳**: 탑바 섹션 라벨 10px·대비 2.80 — 모든 화면 ✅(`hub-tokens.css:1369`), 개인 매출 `✦ 100% 확정` 9.5px + 금색 리터럴 ✅(`hub-tokens.css:2363-2370`), 프로젝트 D-day 배지 10px + raw `rgba(239,68,68,.15)`(`globals.css:2589/2597`), `suggestion-tip.jsx:40`, `automations.jsx:717`, `revenue.jsx:1210`, `my-work.jsx:657`, `hub-topbar.jsx:222`, `quick-memo.module.css:25`.
- **데이터 값이 12px 미만**: OKR 주간 칸 `a/b` 10.5px(`goals.css:334`), 캘린더 일정 블록 제목 11px·시간 10.5px + opacity 0.7(`work.jsx:757-763`), 문의 메타의 이름·상태 11px(`inquiries.css:9`), 히트맵 이름 11.5px·금액 11px, 보드 카드 meta `.mono` 10.5px(`my-work.jsx:2191`).

### 2.3 한글 줄바꿈·행간

- `.hub-app`과 `body` 어디에도 `word-break`·`line-height` 기본값이 없다(`keep-all`은 4개 파일 17회). 390px에서 단어가 음절 중간에 꺾인다 — 오늘 화면의 `0일 대기` 칩이 세로로 `0/일/대/기`로 쪼개지고, `오늘 할 일` 라벨이 두 줄이 된다 ✅ [캡처](today-m-light.png). `globals.css:588` 주석이 이미 같은 사례("지_연")를 기록했다.
- 권장: `.hub-app { word-break: keep-all; overflow-wrap: anywhere; }`. 기본 `line-height: 1.45`는 행 높이 회귀 확인 후.
- 말줄임: 인라인 82곳 중 `title`이 붙은 곳 약 6곳. 탑바 제목·토스트·할 일 제목(`daily-brief.jsx:375`, 모바일은 2줄 clamp 권장)에서 전체 이름을 볼 수 없다.

- 영업·매출 공용 훅을 `revenue-core.jsx`로 떼어 고객·세그먼트·히트맵·현금흐름이 `revenue.jsx` 전체를 끌어오지 않게 함.
- 오늘·홈·내 작업이 같은 daily-brief 응답을 한 번만 요청함. 5분 안에 다시 열면 마지막 정상 응답을 먼저 그림. 실패 응답이나 로그아웃 상태는 재사용하지 않음.

### 8.3 남은 것

- **오피스 세션 provider(86KB)와 빠른 메모 패널 분리**: 첫 번들에 남아 있다. provider는 테스트가 구조를 고정하고 있어 이번에는 손대지 않았다.
- **폰트 서브셋**: SUIT를 한글 사용 범위로 줄이는 작업. 전후 글리프 비교가 필요하다.
- **지연 묶음의 공유 코드 중복**: 위의 약 100KB.
- **390px 오늘 화면**: `오늘 할 일` 라벨이 좁은 열에서 줄바꿈된다.
- **운영자 결정 대기**: §6의 나머지 영문 탭 이름, 탑바 `New` 라벨, Q134 축하 연출.
