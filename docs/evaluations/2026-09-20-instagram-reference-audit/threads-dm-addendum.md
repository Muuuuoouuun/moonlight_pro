# Threads 다른 계정 DM — 브랜드·장르·주제별 추가 정리

수집: 2026-09-20 · 브랜드 매핑 갱신: 2026-09-22

상태: 브랜드 이름·계정 연결은 운영자 제공 사실 / 장르·주제 분석과 활용안은 제안

후속 조사: 2026-09-22에 6개 브랜드·9개 공개 채널을 별도로 살펴보고 [계정별 현재 모습·외부 추세·정체성 및 콘텐츠 초안](brand-direction-first-look-2026-09-22.md)을 작성했다. 아래 DM 수집 범위·건수와 구분하며, 정체성은 운영자와 대화 후 확정한다.

기존 Instagram 레퍼런스 105개에 이어, 사용자가 지정한 다른 계정의 Threads DM에서 **고유 프로필 링크 2개**를 추가로 정리했다. 이 대화에서 확인한 개별 게시물 공유 링크는 **0개**다. 두 프로필의 성격을 파악하기 위해 공개 게시물 5개도 분류 근거로 기록했다. 이 5개는 DM에서 공유한 게시물이 아니므로 DM 수집 건수에 합산하지 않는다.

`미수집`은 게시물이 없다는 뜻이 아니다. 이번 기준표는 사용자 제공 목록의 범위이며, 다른 운영 브랜드가 폐기됐거나 앱에서 삭제됐다는 뜻도 아니다.

분류 순서는 **운영 브랜드 → 장르 → 테마·주제**다. 출처 계정·자료 형식·확인 수준은 각 자료에 별도로 유지한다. 예: `시나브로 → 색채·그래픽 디자인 → 사진 기반 팔레트 → 출처 Arthur França`.

## 수집 범위와 건수

- 지정 DM의 화면에 표시된 대화 시작 소개와 마지막 공유 항목을 확인했다. 위쪽 스크롤 후 컨테이너의 `scrollTop = 0`을 확인했고, 이전 공유 항목은 추가로 나타나지 않았다.
- 표시된 공유 메시지는 2개이며, 각 메시지의 미리보기 카드와 같은 URL 텍스트를 중복 제거해 프로필 링크 2개로 기록했다.
- 서비스의 독립적인 전체 이력 건수와 대조하거나 계정 데이터를 내보내서 검증한 것은 아니다. 확인 범위는 이 로그인 세션에 표시된 지정 대화다.
- 두 프로필에는 DM 미리보기상 각각 게시물 40개·2천개가 표시됐지만, **이 수치는 수집한 게시물 수가 아니다.** 프로필의 전체 게시물을 수집하지 않았다.
- 다른 DM·저장함은 이번 추가 기록의 수집 대상에 포함하지 않았다.
- 캡션과 일부 이미지 화면을 확인했다. 전체 이미지 파일 보관·영상 전사·외부 모델 업로드는 수행하지 않았다.
- 결과는 문서·JSON 레퍼런스에 추가한 상태다. Moonlight 앱의 운영 DB에 등록한 것은 아니다.
