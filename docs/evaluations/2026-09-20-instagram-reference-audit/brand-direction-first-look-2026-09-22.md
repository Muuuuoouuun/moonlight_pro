조사일: 2026-09-22 · 상태: **조사 / 제안 / 운영자 대화 대기**

사용자가 제공한 6개 브랜드·9개 채널을 브라우저에서 확인하고, 관련 외부 조사와 연결했다. 브랜드 이름과 계정 연결은 사용자 제공 사실이다. 아래 정체성 문장·독자 가설·콘텐츠 기획은 확정된 브랜드 전략이 아니다.

관계: [Threads DM 추가 기록](threads-dm-addendum.md)의 후속 공개 계정 조사다. DM에서 공유된 프로필 2개 및 보조 게시물 5개와 이번에 살펴본 운영 계정의 게시물을 구분한다. 이번 조사로 DM 수집 건수는 늘어나지 않는다. 기존 브랜드 스펙과 앱·운영 DB를 변경하지 않았다.

## 3. 브랜드별 정체성·콘텐츠 제안

### 다리 놓는 사람

- **관찰 장르·주제:** 신앙 에세이 / 변증 / 인용 / 종교 유머 → 믿음과 생활, 정의, 도덕, 성숙.
- **정체성 초안:** 신앙의 언어를 일상의 질문과 연결하는 대화자.
- **독자 가설:** 신앙이 생활에서 어떻게 작동하는지 고민하거나, 기독교에 질문을 가진 사람.
- **방향의 선택:** 대화와 변증 중 어디에 무게를 둘지 운영자가 결정. 선명한 입장과 열린 질문은 함께 가능하지만, 반응이 큰 논쟁만 따라가면 다른 계정이 될 수 있음.
- **간이 기획:** ① `월요일의 신학` — “맡긴다는 것은 손을 놓는 일일까?”를 실제 생활 한 장면과 연결. ② `익숙한 신앙 문장 다시 읽기` — 흔한 표현 하나의 의미·오해·내 경험. ③ `한 인용, 한 질문` — 출처를 확인한 짧은 인용에 자기 해석과 질문을 붙이기.

### 고래

- **관찰 장르·주제:** 자기계발 큐레이션 / 동기부여 단문 → 습관, 작은 도전, 재시작, 선택.
- **정체성 초안:** 잘하려다 멈춘 사람들과 함께, 작게 다시 시작하는 실험 일지.
- **독자 가설:** 계획을 세웠다가 멈춘 경험이 있고 부담을 낮춰 재개하고 싶은 사람.
- **방향의 선택:** 조언을 모으는 매거진과 본인의 시도를 기록하는 계정 중 중심을 정하기. 후자를 택한다면 실제 경험이 차별점.
- **간이 기획:** ① `작심삼일 이후` — 4일째 멈춘 이유와 다시 시작한 가장 작은 행동. ② `오늘의 문턱` — 실행을 가로막은 준비·완벽주의를 하나 줄여 본 기록. ③ `일요일 재시작 노트` — 이번 주 멈춘 일 1개, 배운 것 1개, 다음 행동 1개.

### 기독밈

- **관찰 장르·주제:** 종교 밈 / 영상 유머 / 교회 문화 관찰 → 성경 장면, 예배·기도, 신앙과 생활의 간격.
- **정체성 초안:** 신앙생활의 모순과 귀여움을 함께 웃으며 나누는 기독교 밈 계정.
- **독자 가설:** 교회 생활을 해 본 사람이 우선 공감하고, 배경이 없는 사람도 상황 자체를 이해할 수 있는 콘텐츠.
- **방향의 선택:** 따뜻한 생활 공감과 교회 문화 풍자를 어디까지 다룰지 정하기. 확인한 대표 영상의 건설적 비판 방향은 참고 근거이며 최종 의도로 확정하지 않음.
- **간이 기획:** ① `주일의 나 / 월요일의 나` — 결심과 현실의 작은 차이를 직접 만든 상황극으로. ② `교회 생활 번역기` — “짧게 기도하겠습니다” 같은 익숙한 말과 상황의 차이. ③ `성경 인물 POV` — 한 장면을 밈으로 풀고 캡션 한 줄로 본문 맥락 덧붙이기.

### 시나브로

- **관찰 장르·주제:** 시 / 짧은 산문 → 시간, 관계, 아름다움, 상실, 위로.
- **정체성 초안:** 지나가는 감정과 장면을 자기 문장으로 붙잡는 작은 문예지.
- **독자 가설:** 짧은 글을 읽고 자기 경험을 떠올리거나, 문장을 저장해 다시 읽는 사람.
- **방향의 선택:** 직접 쓴 작품 중심인지, 다른 작품의 큐레이션도 포함할지. ‘눈이 부시게’와 ‘시나브로’의 역할도 정리 대상.
- **간이 기획:** ① `같은 장면, 다른 마음` — 같은 길·창문·퇴근길을 다른 날의 문장으로. ② `한 문장을 고치는 일` — 자신의 초고와 퇴고본, 바꾼 이유. ③ `시 뒤의 메모` — 짧은 시와 400~700자 작가 노트.

DM의 팔레트·디자인 레퍼런스는 시각 표현에 활용할 자료다. 그것만으로 시나브로를 디자인 정보 계정이라고 정의하지 않는다.

### 22세기 유목민

- **관찰 장르·주제:** AI·IT 소식 / 도구 소개 / 기술 에세이 → 신제품, 코딩 AI, 업무 활용, 정보 과잉.
- **정체성 초안:** 기술의 큰 약속을 자기 일에서 시험하고, 쓸모와 한계를 기록하는 기술 생활자.
- **독자 가설:** 발표 소식은 이미 접하지만 자기 일에 쓸 수 있는지 판단하기 어려운 사람.
- **방향의 선택:** 빠른 소식·실사용 리뷰·비판적 사유의 비중. 제안은 실사용을 중심으로 소식과 사유를 연결하는 것. ‘미래소년’과 ‘22세기 유목민’의 이름 관계는 미정.
- **간이 기획:** ① `그때 소개한 코딩 AI, 지금도 쓰나?` — 약 2.3만 조회 쇼츠의 후속. 현재 직접 실행한 과제와 수정한 부분을 보여주기. ② `7일 후에도 쓰는 도구` — 첫인상과 일주일 뒤 판단 비교. ③ `AI가 끝낸 일 / 내가 다시 한 일` — 결과물 한 개에서 실제 분업 설명.

과거 영상의 모델 성능·요금·사용 가능 조건을 현재 사실로 재사용하지 않는다. 후속 콘텐츠에서 현재 제품을 다시 확인하는 것이 기획의 핵심이다.

### 정상화

- **관찰 장르·주제:** 정치·시사 논평 / 비판 / 이미지 공유 → 권력, 민주주의, 시민 참여, 언론의 해석.
- **정체성 초안:** 분명한 의견과 추적 가능한 근거를 함께 제시하는 시사 논평.
- **독자 가설:** 논평을 읽으면서 원문과 판단 근거까지 확인하고 싶은 사람.
- **방향의 선택:** 선명한 논평·쟁점 설명·주장 검증 중 중심을 정하기. 현재 공개 편집 경향을 관찰한 것이며 운영자의 개인적 정치 신념을 별도로 추정하지 않음.
- **간이 기획:** ① `주장 하나 뜯어보기` — 확인된 사실 / 내 해석 / 아직 모르는 점. ② `발언의 앞뒤` — 공식 원문 링크와 짧은 논평. ③ `그 정책, 이후에는?` — 발표 뒤 확인할 지표·진행 상황을 같은 양식으로 추적.

이번에 본 게시물의 정치적 주장 자체는 검증하지 않았다. 여기서 제안한 것은 개별 주장을 지지하는 논거가 아니라 앞으로 사용할 편집 형식이다.

## 4. 서로 겹치지 않게 나누는 기준 — 제안

| 브랜드 | 독자가 가져갈 것 | 겹치는 소재를 나누는 예 |
|---|---|---|
| 다리 놓는 사람 | 신앙에 관해 생각할 질문 | 같은 교회 장면을 신앙과 삶의 질문으로 풀기 |
| 기독밈 | 공감하며 나눌 웃음 | 같은 장면을 상황·반전 중심으로 표현 |
| 고래 | 다시 해볼 작은 행동 | AI를 써서 공부를 재개한 사람의 과정 |
| 22세기 유목민 | 도구를 쓸지 결정할 근거 | 그 공부 도구의 실제 결과와 한계 |
| 시나브로 | 오래 남는 문장·감각 | 재시작의 감정을 시와 산문으로 표현 |
| 정상화 | 공적 사안을 판단할 근거와 관점 | 개인 경험이 공적 쟁점과 연결될 때 출처와 논평으로 전개 |

운영 방식은 **브랜드 6개를 구분하되, 다음 2주는 선택한 2개만 새 연재를 시험하는 안**을 권한다. 6개를 모두 순환하면 폭넓게 반응을 볼 수 있지만 제작 부담이 커진다. 하나의 개인 계정으로 합치면 운영은 단순해지지만, 현재의 장르와 독자 기대가 섞인다. 통합이나 우선 브랜드 선택은 확정하지 않는다.

2주 실험은 각 선택 브랜드에서 시리즈 1개·게시물 3개 정도가 출발점이다. 정상화처럼 이미 활동 중인 계정은 기존 발행 속도를 늘리기보다 일부를 새 형식으로 바꾸는 방식이 적합하다. 업로드·예약 발행은 이번 작업 범위가 아니다.

각 게시물은 원문 하나에서 시작해 필요한 채널로만 변환한다. 같은 게시 후 경과 시간에 확인 가능한 조회·답글·저장·공유를 기록하고, 만들 때 든 시간과 ‘다음 편을 만들 수 있는가’를 함께 본다. 계정마다 노출과 지표가 달라 단순 순위를 매기지 않는다. 표본 3개는 연재를 계속할지 논의하는 자료이며 통계적 성과 검증은 아니다.

## 5. 운영자와 정할 질문 5개

1. 앞으로 한 달, 가장 먼저 키우고 싶은 브랜드 2개는?
2. 다리 놓는 사람은 ‘신앙·삶의 대화’와 ‘기독교 변증·논쟁’ 중 어디에 더 가깝길 원하는가?
3. 고래는 ‘내가 다시 도전하는 실험 기록’, 시나브로는 ‘내가 직접 쓴 시·짧은 글’로 나누면 본래 의도에 맞는가?
4. 기독밈은 ‘따뜻한 생활 공감’과 ‘교회 문화를 짚는 풍자’ 중 어디까지 하고 싶은가?
5. 22세기 유목민은 ‘빠른 기술 소식 / 실사용 리뷰 / 비판적 사유’, 정상화는 ‘선명한 논평 / 쟁점 설명 / 주장 검증’ 중 각각 무엇을 중심에 두고 싶은가?

답을 받은 뒤 정체성 한 문장·핵심 독자·다룰 주제·말투·첫 연재를 좁힌다. 이 문서는 대화의 출발점이며 확정 스펙을 대신하지 않는다.
