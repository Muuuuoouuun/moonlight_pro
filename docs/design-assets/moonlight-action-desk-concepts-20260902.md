## A — Command Focus

Make the urgent KA a dominant horizontal command card below Quick Capture. Put today's agenda in a narrow right rail, then a three-row focus-customer list and compact required checklist below. Eye path: Capture → urgent KA → exact next action → focus customers.

## B — Chronological Runway

Make a central time runway the dominant structure, mixing events and required actions in chronological order. Add a slim focus-customer dock and a sticky next-action command beside the current-time marker. Feel like a calm flight plan, not a calendar clone.

## C — Triage Matrix

Build a three-column action matrix labeled `지금`, `집중`, `대기`. Keep the urgent KA and checklist in the wider first column, three focus customers in the center, and agenda plus waiting dependencies in the third. Add the command sentence `먼저, 약속한 제안서를 보내세요.` and one `15분 집중 시작` CTA.
