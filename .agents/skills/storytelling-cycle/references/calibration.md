# 심리 기제와 한국 B2B 캘리브레이션

원고의 장면 하나하나가 왜 작동하는지 알면, 되는 조건과 안 되는 조건을 구분할 수 있다. 미국 숏폼 문법을 한국 B2B에 그대로 옮기면 실패하는 지점은 "기제는 같은데 조건이 다른" 곳이다.

## 1. 5단계 파이프라인
주목 → 유지 → 기억 → 행동 → 전파. 원고마다 주로 맡는 단계를 하나 정한다.

| 단계 | 병목 | 쓰는 기제 |
|---|---|---|
| 주목 | 선택적 주의 | 정보 격차(적정 크기) · 손실 프레임(화자 신뢰 전제) · 구체적·이질적 장면 · 자기관련성 |
| 유지 | 습관화 | 자극 종류 교체(숫자 → 화면 → 사람 목소리) · 열린 질문 · 약속한 것을 앞에서 이행 · 서사 |
| 기억 | 인출 단서 | 이중 부호화(화면=말) · 같은 결론 문장 반복 · 기존 스키마 유추 · 시그니처 형식 |
| 행동 | 저항·지연 | 상호성(영업 냄새 없는 진단) · 작은 행동 먼저 · 날짜·시간이 있는 다음 행동 · 결론을 시청자가 내리게 |
| 전파 | 전달 비용·사회적 위험 | 근접 규범 · 전달하면 전달자가 유능해 보이는 내용 · 내집단 언어 |

## 2. 한국 B2B에서 강한 것
- **근접 규범**: "같은 지역·같은 업종·비슷한 규모 N곳이". 단 실제 데이터가 있을 때만. 없는 숫자를 만들지 말고 있는 숫자를 가장 가까운 단위로 쪼갠다.
- **손실 = 돈 + 평판**: "고객(학부모)이 먼저 알고 대표가 제일 늦게 아는 구조", "사람이 나갈 때 같이 나가는 것".
- **상호성**: 진단 시트·점검표는 영업 연락 없이도 완결된 가치여야 한다.

## 3. 한국 B2B에서 약하거나 역효과인 것
| 기제 | 이유 | 대체 |
|---|---|---|
| 충격형 기대 위반 훅 | 화자 신뢰 부재 + 광고 회의론 → "업자" 분류 | 정밀 숫자 + 측정 조건 공개 |
| 큰 예산 볼거리 | "우리 돈으로 광고하네" | 공개하기 어려운 것을 공개(실제 화면·실제 수업 전체) |
| 직접 클로징 | 저항 + 거절 부담 | 사라고 말하지 않기, 다음 행동을 작고 구체적으로 |
| 실패 실명 공개 | 체면 손상 | 실패는 익명·유형화, 성공만 실명(동의 시) |

## 4. 반복해서 효과가 좋았던 장치
- **책임을 구조로**: "선생님 잘못이 아닙니다. 저장할 곳이 없었을 뿐." → 실무자가 공유한다.
- **정직한 양보 1컷**: "더 비싸 보일 수 있습니다", "카톡은 남겨뒀습니다, 다 대체한다고는 안 할게요." → 광고 회의론을 누른다.
- **사람 대신 물건이 범인**: 감시·평가로 읽힐 장면은 사건을 네트워크·공유기·노트북 같은 물건 문제로 바꾼다.
- **세어봤습니다**: 스톱워치·계수기·정(正)자. 지어낸 숫자 대신 직접 센 숫자.
- **형식이 곧 콘셉트**: "50분 수업을 50초로"처럼 영상 길이·구조 자체가 메시지.
- **새 고통 발견**: 시대가 만든 새 문제(예: 학생이 밤에 범용 AI로 수업과 다른 풀이를 배워 온다)는 훅이 가장 강하다.

## 5. 손실형 순환 규칙
같은 독자에게 손실형을 3번 연속 보내지 않는다(화자 신뢰 소모). 손실 → 증거 → 사례 순으로 순환한다.
