# ★ 디벨롭 원고 템플릿

````markdown
### ★ R{라운드}-{A|B|C…}. 「{제목}」 ({원안 번호} 디벨롭 · {1차 점수} → **{디벨롭 후 점수}**)

- **파이프라인 위치**: 주목 / 유지 / 기억 / 행동 / 전파 중 + 시리즈·연재 역할
- **핵심 기제**: 2~3개 (예: 손실의 시각화 · 저강도 반전 · 자기관련성 질문 엔딩)
- **디벨롭에서 고친 약점** (경합 라운드면 **경합 후 고친 것**): 원안의 약점 → 바꾼 장면

**촬영 전 실측** (숫자가 있는 편만): 누구를, 어떤 조건으로, 무엇을 세는지 → `[E]`·`[P]` 같은 빈칸 이름

| 시간 | 화면 | 자막 | 내레이션 | 사운드 |
|---|---|---|---|---|
| 0–3 | 첫 프레임 = 썸네일. 가장 구체적인 장면 | 14자 안팎 한 줄 | 자막과 같은 말 | |
| … | 12·25·38초 부근에 자극 종류가 바뀌는 재훅 | | | 무음 0.5~1초도 재훅이 된다 |
| 마지막 3–4초 | 첫 컷으로 돌아가는 루프 | 구매자가 자기 회사에 대입하는 질문 | 같은 질문 | 첫 컷과 같은 소리 |

- **촬영 준비**: 장소·인원·소품·동의서·화면 녹화 출처
- **캡션**: 2~3문장 + 댓글 키워드 CTA (예: "댓글에 `칠판`")
- **연결 자료**: 리드마그넷·쇼룸·상담 중 하나
- **확인 사항**: 미확인 기능·수치·표현 리스크, 확인 안 될 때의 대체 장면
- **A/B 변수 하나**: 무엇을 바꾸고 어떤 지표로 보는지
````

## 공통 제작 규칙 (문서 §0에 한 번 적는다)

- 첫 프레임이 곧 썸네일. 로고·인트로 없음, 로고는 마지막 2초 우하단에 작게.
- 자막은 영상에 입힌다(무음 시청 기본). 한 화면 한 줄 14자 안팎.
- 내레이션 분량: 한국어 초당 4~4.5음절 → 50초 약 190~220음절. 무음 구간을 일부러 넣는다.
- 루프 엔딩: 마지막 컷이 첫 컷으로 이어지면 재시청이 붙는다.
- 재연 장면은 첫 화면 구석에 `재연` 표기.
- 실측 수치는 영상 안에 측정 조건을 1초 자막으로 밝힌다(예: "실제 수업 1회 · 강사 동의 · 고정 카메라").
- 미성년자 등장 시 보호자 동의, 오답·실수는 이름을 가린다.
- 경쟁 제품은 로고를 가리고 "틀렸다"가 아니라 "다르다"로만 말한다.

## 연재 포맷 설계

같은 형식에 대상만 바꾸면 처리 유창성이 생기고 제작이 빨라진다. 연재 원고에는 고정 문법을 적는다.
예) "세어봤습니다": 계수기/스톱워치 → "먼저 맞혀보세요" → 측정 조건 1초 → 실측 타임랩스 → 숫자 정지 → 대비 → "내일 세어보세요".
연재 회차는 TOP 9에서 한 슬롯으로 묶는다.
